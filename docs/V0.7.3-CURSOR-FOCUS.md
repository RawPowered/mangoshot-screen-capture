# MangoShot v0.7.3 — Cursor Focus and tutorial workflow

Development preview based on the Studio Precision branch. No manifest bump, no store publication. No third-party code or new manifest permissions. The existing independent caption branch is not merged in this patch.

## Live recording

Record Studio > Cursor Focus has Off, soft spotlight, cursor ring, tutorial click-zoom, follow zoom and deep detail presets. Adjust dimming, feather, radius, ring color, camera scale, smoothing and click hold. Spotlight and ring are composited before ink; Ctrl+E still clears only ink. Existing manual zoom controls disable automatic zoom to avoid fighting the camera. Cursor-only preview tool prevents accidental strokes; region and modifier zoom remain available.

Preview mouse positions map back through the previous rendered camera crop. Linked source tracking is available only after a browser-tab capture and explicit same-tab confirmation and connection to the already-authorized page. The display picker does not reliably expose captured tab identity; the user must confirm it and disconnect if sharing changes. No global mouse tracking. No tracking outside the linked top-level page or inside uninstrumented cross-origin frames. Native window/desktop capture supports only pointer movement in the MangoShot preview. The browser may throttle background rendering. Reconfirm the selected tab after a pause, manual disconnect or source navigation. A post zoom requires time for both transitions and the requested hold. Live spotlight/zoom is baked into recorded pixels and cannot be removed later. Use Off plus optional path retention to record an unaffected video for post work.

## Cursor path and Clip Studio

Opt-in path samples use recorded-frame normalized coordinates at approximately 5 Hz with gaps and a cap of 18,000 samples (approximately one hour of continuous sampling). Paused time is excluded; no path attached for incomplete/recovered fragments. Local handoff is bound to the immutable recording ID. Stop, pause, disconnect, navigation and pagehide terminate or suspend linked tracking. No URLs, DOM text, keypresses, or network export are captured. Clear local clip cache to remove retained metadata. A path may contain baked live camera/spotlight effects, so choose a clean recording for maximum post-edit flexibility. Trace is available only with the local handoff, not arbitrary MP4/WebM files; downloadable JSON is provided for inspection/automation, not yet a re-importable portable asset.

Clip Studio Properties > Cursor Focus: position playhead over a tracked moment, add a smooth zoom and return with existing undoable camera keyframes. Source time maps through the retained sequence segments so cuts do not shift the pointer to the wrong source position. Save Project V2 to preserve camera keyframes. Existing V1 export does not save camera keyframes. Live cursor effects are separate from editable post zoom; post-production editable spotlight tracks, automatic click detection and external cursor-path re-import are follow-on work.

## Declarative scripting

The same validated command path powers the controls and JSON recipe panels. No eval, shell, native bridge or MCP server exposed. External MCP can later call these typed operations through a permission-scoped bridge.

Recorder recipe:
~~~json
{"schema":"mangoshot.cursor.recipe.v1","action":"recorder.cursor.configure","preset":"tutorial","settings":{"scale":2,"radius":10,"dim":0.5}}
~~~
Clip recipe (at is edited sequence seconds; omit to use playhead):
~~~json
{"schema":"mangoshot.cursor.recipe.v1","action":"clip.cursor.zoom","at":12.5,"scale":2,"transition":0.4,"hold":1.8}
~~~
Recipes do not enable permissions, start capture, connect a tab, or enable path retention. Values and recipe size are bounded; incompatible actions and missing samples fail rather than guessing coordinates.
