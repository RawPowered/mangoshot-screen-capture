# Spatial Motion & Foreground Occlusion v0.7.31
Development branch from ace2bad1613a1b2c6b192d8fa3071476c0a574ec. v0.7.30 browser qualification was still in progress when branched; preserve the last verified package until the entire new suite passes.

## Motion
- Sequence Studio spatial arrows, not legacy extrusions/Clip Studio. Two to twelve normalized clip-local keyframes with fixed XYZ point topology, explicit endpoints, 1% minimum spacing. Interpolate point coordinates, tube/head dimensions, RGB, light, camera target, FOV, distance, elevation and shortest-path azimuth. Material, smooth/polyline and projection changes are held until the next key. Linear/smoothstep/hold per outgoing key. Full key pose uses existing XYZ gizmos; no topology changes while motion enabled. Analytical adjacent-edge collision guard rejects interpolation that collapses neighboring nodes; it is not a general self-intersection solver. Rotation/translation/scaling are pose morphs, not quaternion rigid-body transforms.
- Reveal parameter 0–100% per key clips the true sampled centerline by accumulated arc length. Tube and head generated at the advancing endpoint. Zero renders transparent, small reveals scale head/tube. Grow preset; scrub, insert intermediate pose, edit time, remove interior key, play local preview. Preview reference is a still frame, not decoded moving footage; real monitor and export evaluate on timeline. Same WebGL2 depth-tested mesh painter, transient surfaces released immediately rather than filling static LRU. Real-time encoder may drop frames at large resolutions; no certified frame rate or deterministic offline encoder.
- Sequence v6 stores normalized keys and a canonical first pose. Move/trim scales normalized key timing with clip span. Previous sequence v3–v5 supported. Existing speed ramps unaffected.

## Occlusion
- Image and Sequence spatial arrows: draw up to four closed foreground polygons with 3–64 normalized layer-frame vertices each. Transparent destination-out cuts only the rendered arrow, leaving screenshot/video, layers, original XYZ geometry intact. Remove last or clear all. Mask outlines shown in editor only. Foreground masks are screen-space and static; no automatic depth inference, object segmentation, camera tracking, time-varying mask shape, or cross-layer scene depth. Use on fixed camera footage or manually split clips; masks follow layer placement. Arrow shadows/effects are applied by existing image compositor after masking. Not security redaction.
- Image v9 for masked spatial layers; v1–v8 compatibility retained. Sequence v6 for motion or foreground masks. No new permissions or dependencies.
