# MangoShot v0.6.6 — Workspace Polish & Studio II Preset Pack (Alpha 7)

## Visual and workspace polish
- Three directly draggable boundaries: Properties width, Program Monitor vs Timeline height, and Timeline vs Media Library height.
- Saved layout dimensions **independently for Edit, Graphics and Timeline workspaces** in extension-local storage. Mouse, pen, touch and keyboard arrows are supported. Shift+Arrows makes larger adjustments; double-click a divider to reset that dimension.
- **Panels** menu beside the existing workspace buttons: Balanced, Editing Focus, Preview Focus, Graphics Focus, Timeline Focus, Reset. View menu also offers Reset Panel Layout.
- Preserves the viewport-fitted desktop editor, local scrolling per panel and always-accessible pinned Media Import. Compact responsive behavior remains available on smaller windows.
- Source monitor aspect ratio updates from decoded video metadata. Buttons, keyboard focus and separators use consistent gunmetal/charcoal and lime styling.

## Studio Preset Pack II
Eight new native MangoGraphics presets with actual Canvas rendering and project save/reload support:
1. Editorial / Magazine (serif title)
2. Impact Motion (bold high-contrast)
3. Technical Note (monospace callout)
4. Soft Badge (rounded lime)
5. Quote Card (editorial quotation)
6. Pointer Pop (orange action callout)
7. Premium Title (muted metallic)
8. Checklist (compact monospace card)

- Core / Studio II / All filters prevent a 19-card list from overwhelming the Properties inspector.
- Quick +Text and +Callout buttons apply the chosen style to newly inserted layers. Selecting an existing graphic applies a preview style to that layer through the existing undoable editor.
- Existing style dropdowns remain accessible and include the new presets. Preset properties and identifiers are saved in edit project metadata; no font files or external resources are bundled.

## Delivery and performance
- Layout drags are coalesced to one browser animation frame; saved to disk/localStorage only when the gesture finishes. No source-video re-encoding occurs during resizing.
- The Media Bin avoids reconstructing its asset rows on every timeline refresh if imported assets, selection and staging are unchanged, while keeping action availability current.
- Consistent small SVG icons for recording import, latest recording, export, AutoCut, snapping, graphics shortcuts and related actions. No change to recording capture engine or its permissions.
- This optimizes editor interaction work, **not** the fundamental real-time browser export pipeline. Rendering-speed optimization is a distinct future task requiring codec hardware support profiling.

## Install / rollback
- An incremental v0.6.5 → v0.6.6 overlay is provided for existing unpacked v0.6.5 installations only.
- Back up the extension folder and export important recordings/projects, then extract into the SAME folder containing \`manifest.json\` and reload the extension.
- The full v0.6.6 ZIP is available for clean installs or older baselines. Restore your backed-up v0.6.5 files at the same path to roll back without clearing browser storage.
- This is a prerelease and still requires Windows/Chrome/Edge/Firefox/Wacom visual QA, including small viewports, varied monitor aspect ratios and actual drag/keyboard interactions.
