# Multitrack Studio — development preview

Baseline v0.7.15. The prior browser run passed Layer Studio, Cinematic and Professional Compositor, then failed at rotated-image masking. The shared tool selector now retains the selected image in mask mode.

V2/V3 are prepared local visual overlay tracks; A2 is separately imported audio. Use the modal to add media, set timeline and source-in timing, fit, position, opacity, visibility/locking, volume/mute and per-clip color looks. Existing graphics remain above overlays. Primary duration and audio are retained. Stage is inert until explicit preparation/apply. Undo/redo, V2 project persistence and reviewed still-frame rendering preserve the secondary model; V1 save refuses active secondary media. Missing media must be relinked, and output preflight rejects missing frames or audio. Primary duration-changing trims/ripples are blocked while secondary clips exist. Existing voiceover remains separate.

Limits: 16 clips, 64 MiB per local file, 150 sampled visual frames at 15 fps (roughly 10 total seconds of moving overlays), 64 MiB nominal raster cache, secondary frames up to 960x540 with budget-dependent reduction, 24 MP decoded source dimension cap, animated GIF via supported ImageDecoder only (120 source frames max), audio source at most 120 seconds and 12 million decoded channel samples. Secondary video is visual-only, audio must be imported separately. Same-track overlaps rejected. Real-time browser export; not frame-exact offline rendering. No multi-source transitions, sequence extension or direct timeline keyframe marker editing. No permission changes or stable/main promotion.

CI retains earlier tests and adds pure track validation, actual decoded secondary video, mixed audio in downloaded WebM, V2 roundtrip, undo/redo and compact modal. Still image, GIF, relinking, cross-browser, hardware and 4K performance are separate runtime qualification tasks.
