# MangoShot v0.6.15 — Synchronized Tool Properties & Vector Shapes (Alpha 1)

## Image Studio
Tool selection and properties now share one coherent UI state. Clicking a rail tool activates the matching inspector: Pen, Highlighter, Eraser, Redact or Vector opens Tools; Text opens Type; Mask opens Mask; Select routes to properties appropriate for the selected layer.

Properties display the current tool name and description. Stroke color, width, opacity, fill color, fill enable, outline style, corner radius, star points and arrowhead placement have visual controls. Current tool settings apply to new objects. Selecting an existing vector from the canvas or Layers exposes editable non-destructive properties.

New path-based editable vector shapes:
- Rectangle; Rounded rectangle; Ellipse; Straight line; Arrow (head none/start/end/both)
- Triangle; Diamond; Pentagon; Hexagon; Star (4–12 points); Speech bubble

Vector shapes support solid/dashed/dotted borders, optional fill, opacity, adjustable outline width, individual visibility/lock, Undo/Redo and existing layer-stack operations. Vectors can be moved and resized using the same proportional corner handles as text and images (hold Shift to free-stretch). All attributes remain editable and render through the Canvas painter shared by live preview, clipboard and PNG/PDF export. The edit model is vector, but exported PNG/PDF snapshots rasterize annotations as expected.

Original screenshot pixels are preserved. Legacy rectangle and arrow strokes are still readable/editable. Redact remains a separate pixel-hiding operation. A visually opaque vector shape must not be treated as a secure redaction technique.

## Clip Studio
Select, Razor and Range are persistent modes; Text, Callout and AutoCut are actions, not modes. A new always-visible current-tool label in transport displays SELECT / RAZOR / RANGE. Mode state is shared across the rail, native timeline controls, accessibility pressed state, keyboard shortcuts V/C/R and timeline cursor. Range can no longer be active without a corresponding highlight.

The rail dispatches through the existing Clip Studio controllers rather than overriding appearance without activating a real tool.

## Installation
Overlay requires an unpacked v0.6.14-quick-copy-alpha.1 installation. Back up the root holding manifest.json and important captures; extract the overlay over that same directory and reload via edge://extensions or chrome://extensions, or Firefox about:debugging.

For older versions, use the full extension ZIP. Roll back by restoring the backed-up v0.6.14 directory and reloading. Do not uninstall or clear extension storage, which may contain recordings.

## Validation
Automated: existing capture/quick-copy, Image Studio, masking, live text, Clip Studio, recorder and export regressions; new 11-shape Canvas paint/geometry, undoable move/resize, JSON model and UI tests; Clip Studio tool-mode synchronization tests; ZIP CRC, runtime member/diff and SHA-256 checks.

Manual Chrome/Edge/Firefox acceptance remains: Wacom/pen/highlighter/eraser, shapes layered over imported images, selecting/resizing/free-stretch, clipboard/PNG/PDF parity, and Clip Studio keyboard/rail state. Keep this as a prerelease/draft until real-browser QA passes.
