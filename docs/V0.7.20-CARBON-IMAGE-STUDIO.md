# Carbon Image Studio — v0.7.20 development preview

Base: df36db3a5ae577f008a96559158e2b952d233a6d (Professional Sequence v0.7.19). No stable release, main merge, permission increase, engine substitution, or manifest-version change.

## User-facing pass
- Quick workspace chooser: annotation, graphic design, typography, mask editing, and canvas focus. Uses the existing saved layout API, not a second layout system.
- Persistent layer dock (wide right-side layout, at least 1100×660), automatically returns the *original* filter, selection actions and layer list to the Layers tab on compact or bottom-docked layouts. Local pin preference. Original IDs, native handlers, keyboard commands, undo and export retained. The dock is not a true group compositor or thumbnail system.
- Carbon panel tabs, direct shortcuts to existing Layers, Effects, Material and Creative Library.
- Precision Studio for one visible unlocked eligible layer: rotary drag controls with number entry, keyboard adjustment, reset, original/draft side-by-side Canvas2D composition, explicit Apply or Cancel/Escape. The draft invokes the actual Layer Studio renderer; no CSS filter approximation. Rotation, opacity, shadow/glow and softness supported. Apply uses the revision-checked existing layer transaction once. Preview is scaled and may differ at pixel-level from full-resolution export.
- Compact viewport falls back to the original inspector and does not claim draggable detachable OS windows. Existing workspace save/restore is retained.

## MangoEngine research
The dependency-free Rust grayscale kernel lives under experiments/mango-engine, not in the shipped editor. It compiles as a native test and wasm32-unknown-unknown cdylib. The Node benchmark uses seeded 1080p/4K RGBA, exact JS parity including alpha, a bounded owned buffer, and copy-inclusive timings. No unsafe code, CSP loosening, WebGPU, real extension Wasm activation or performance claims. Actual browser extension packaging/CSP and worker/render parity must be separately qualified before integrating. Keep the Canvas2D renderer authoritative.

## Gates
- All existing unit and real Chromium tests, new dial contract and real extension browser tests, preview screenshots and deterministic ZIP.
- New browser test checks persistent dock, draft isolation, real rotated ink pixels, single undo, Escape cancellation, compact restore and canvas-focus layouts.
- Rust native and Wasm/Node tests are experimental; no promotion based on a single grayscale timing.
- Manual Windows Chrome, Edge, Firefox, Wacom pen/eraser, high-DPI and 4K/long screenshot tests pending. Review screenshots before stable promotion.
