## Compositor contract
- Explicit isolated render groups independent of organizational folders. Select at least two adjacent eligible annotation layers. Strictly nested groups (up to three levels), each rendered to transparent isolated canvas then blended once into parent. Group name, visibility, opacity, six blend modes, sibling group move, ungroup, before/draft preview. Group blend operates on annotation composition (not across original screenshot). The flat layer stack stays authoritative. Group ranges contiguous; legacy individual moves that would split a group are rejected. Single duplicate/clipboard paste/Alt-clone inserted outside outermost group; batch copies ungrouped. Group membership pruned on layer deletion, groups with fewer than two members removed. Protected redaction and eraser layers cannot enter isolated groups. Group edits respect locked descendants. Existing layer folder paths unchanged.
- Ordered non-destructive SOURCE adjustments: exposure, contrast, saturation, warmth/sepia, hue, monochrome, invert. Up to eight editable enabled nodes, applied to original screenshot below annotations, not a full-composite adjustment at arbitrary z-position. Original base pixels remain immutable; standard combined exports, Layer Studio previews and Raster Lab use adjusted source. Copy original keeps original. No blur in source-adjustment stack. No destructive changes to original. Independent group and adjustment UI, layer membership labels, one undo/redo transaction.
- Project v1 remains supported; v2 includes composition when groups/adjustments exist. Validation checks contiguous nested membership, known layer identities, no protected members, numeric values, decoded project limits and group scratch budget. v2 needs a compatible reader. Editable project source remains sensitive.
- 16 MP max individual active composition; group depth plus adjustment scratch budget 32 MP (excludes existing renderer buffers); up to 32 groups. No GPU or new permissions. Existing Raster Lab Rust processing retained. No arbitrary full-image adjustment above annotation/redaction, group clipping masks, pressure curves, editable Rust effects or multistop gradients in this pass. These require separate integration.
- Qualification: existing all regression gates, new pure model tests and actual Chromium pixels for isolated alpha, nested range, unchanged redaction and raw source, undo/redo and v2 roundtrip, deterministic ZIP. Manual Firefox/Edge/Wacom and memory/performance stress still needed.
