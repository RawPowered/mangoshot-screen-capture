# v0.7.37 Smart Focus Studio (development)

Base 747869ab8addc7d29f2cc6110e0d76d82a7ee025 (v0.7.36 Callout Motion). Preserve v0.7.35 qualified preview until later gates pass; separate from the parallel precision 3D modeling work.

Sequence Studio adds a Smart Focus button and a contextual Focus tab in Callout Designer. Six reusable focus recipes configure a real magnifying lens or anchor an existing callout to a screen point. One clip links lens/annotation, leader and target marker; no separate track is consumed by the leader. Lens samples clean composited local video/stills before any graphics, preserving source aspect ratio and clamping at edges; ellipse/rounded rectangular masks, 1–6x start/end zoom, feather, outside dim, caption and existing clip opacity/fades/rotation/glow/entry-exit. Independent v11 geometry keys animate the lens; start/end zoom and target sweep use linear or smoothstep interpolation. Targets can stay fixed, sweep between two manually picked coordinates or follow the evaluated clip center. Target rings, crosshairs and region brackets; straight/elbow/none leaders. All staging applies atomically using the existing undo/redo transaction. New Smart Focus clip uses a selected preset; choosing a focus recipe within an existing clip changes focus settings only, not callout shape or transform/keyframes. The inspector samples clean local media explicitly for lenses (grid otherwise); sampled still is not live footage playback. Normal program playback and WebM/MP4 export use current decoded frames. One reusable clean frame and one bounded scratch surface (max frame dimensions and 8 MP) per renderer, released on pool/inspector close. No new permissions, remote assets or dependencies.

Native v12 stores validated focus recipe only on 2D callouts. v3-v11 continue to load; previous 3D paths are unchanged. Move preserves normalized target and animation; trim retimes all clip-relative effects. Max two overlapping G2/G3 effects still applies. Target is screen-relative, not automatic tracking of source pixels or cursor; near-edge crop can shift the target away from lens center to avoid blank pixels. Lens does not sample graphics, including other lenses. Not a privacy-redaction tool. No interactive viewer hyperlinks, camera/cursor linking across legacy editors, custom multi-clip sequences or Bezier spatial tangent editing yet.

Unit tests cover schema, bounded values, crop/edge geometry, target interpolation, move/lock/save and compatibility. Browser gate uses locally generated two-color video, actual magnified pixels in preview and encoded frames, controls, target picking, native save and anchor editing. Hardware performance, Firefox/Edge and final screenshot QA remain distinct gates. No stable release or main merge.
