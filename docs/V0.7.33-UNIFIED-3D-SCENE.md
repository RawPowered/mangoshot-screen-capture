# v0.7.33 Unified 3D Scene
Branch from 52606bcf1fc8cd5e5ef6103a8b8c935065c0594c; prior v0.7.32 browser gate still running at branch creation. No stable merge.

## Scene contract
- New editable layer/graphics clip (mode scene), 1–8 opaque procedural meshes using a single shared XYZ coordinate system, camera, projection and WebGL2 depth buffer. Clear depth only once per scene, draw per-object material and geometry with hardware depth testing. Object draw order does not substitute for depth; equal-depth surfaces can still z-fight. Scene foreground polygons are applied once after shared-depth rasterization. Ordinary 2D layer opacity, placement, fades and outer effects apply to entire scene. Individual object transparency is not supported.
- Scene explorer selects objects by list or projected origin labels. Add any of the six primitives, rename, hide/show, lock/unlock geometry, duplicate or remove (at least one remains). The existing path-point and whole-object XYZ gizmos, numeric editing, axis-rotation buttons, ray/plane-based draggable XYZ rotation rings, uniform drag-scale ring, camera orbit/pan/dolly and inspection views operate in a viewport rendering the complete scene. Only selected object has full gizmos. Shared camera is stored once, foreground polygons shared; geometry stores no per-object camera/mask. Hidden objects remain editable in list. Locked object cannot be deleted/duplicated or edited through geometry controls. Entire layer locked remains non-editable. Independent object names and IDs persist.
- Separate Image Studio 3D Scene launch and Sequence Studio 3D scene clip action. Local footage reference sampling can refresh a still at selected clip time, excluding the scene. Older single-object spatial layers and motion remain supported. Native image v11 and sequence v8; mixed older formats remain readable. No new permissions/dependencies.
- Scope: scenes are static geometry across a clip with existing clip timing and fades. Independent older spatial clips retain pose/reveal/keyed-mask animation. Per-object keyframes and shared camera animation within unified scene, Bezier tangent handles, reusable preset library, GLTF import and camera solving are not implemented here. Reference footage is 2D, and depth does not extend across other layers or inferred game geometry. Scene cache inherits 9 MP per surface, 18 MP total, six entries; up to 8 bounded meshes per scene. No hardware FPS certification.
- Gates: model checks for IDs, shared camera, isolation, locks and budgets; actual WebGL2 occlusion with reverse draw order and hidden near object; image v11 exact reopen and visibility undo; sequence v8 saved multi-object geometry and encoded output; all prior tests remain enabled.
