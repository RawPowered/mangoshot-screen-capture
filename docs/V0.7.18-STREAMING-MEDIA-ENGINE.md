# Streaming Media Engine — 0.7.18 development preview

Baseline d283c7ef34c647b8c04c57d27d1126d5e648fb12. Its Chromium qualification independently passed actual multitrack WebM/video/audio and professional timeline gestures; rotated-mask qualification failed because the capture store consumes a stored capture on first load. This branch seeds a distinct capture for the mask test and keeps all prior tests.

Secondary video now uses browser-native HTMLVideoElement decoding from local Blob URLs. Preparation probes actual dimensions/duration rather than sampling the entire source. Active V2/V3 streams use at most two decoders per pool. Inactive streams release elements; seek cancellation invalidates the generation. Compositing draws decoded video at source resolution into the primary output canvas (contain/cover/stretch and existing per-clip grades). No fixed 15 fps video cache, no 150-video-frame limit, and no 960x540 cache downsample for native video. GIFs and still images retain the bounded existing cache; audio remains decoded Web Audio.

Preview partitions the primary playback mapping at visible secondary start/end boundaries without changing project cut decisions. It seeks and primes active decoders before playback/resume and checks clock drift; bounded playback-rate correction applies between checks. Pending paused frames have an explicit decoding message. The encoder uses the same interval partition, pauses MediaRecorder during seek barriers, resumes the primary and secondary video clocks together, mixes A2 and voiceover and rejects an export if a required frame is missing/outside 0.32 s clock tolerance. This is best-effort real-time synchronization, not verified frame-exact offline rendering. Reviewed frames use isolated paused native decoders; review generation checks occur after async decoding.

Resource limits retained: 512 MiB per secondary video, 24 MP decoded dimensions, 16 secondary clips, two active visual tracks; primary sequence duration still determines the output. Secondary videos remain visual-only; import audio separately on A2. Still/GIF sampled raster budget 64 MiB/150 samples; audio 64 MiB file, 120-second source, 12 million decoded channel samples. Native/browser/GPU buffers are not included in the raster count and require representative hardware measurement. No multi-source transitions or independent sequence duration yet. No new extension permissions, no main/stable promotion.

CI adds a real 18-second primary and 14-second 720p secondary sequence with color changes, overlapping picture-in-picture, repeated exact scrubs, isolated reviewed-frame pixels, playback over a secondary boundary, actual encoded timeline color checks, and decoder/cache assertions. Browser result is required for extension packaging.
