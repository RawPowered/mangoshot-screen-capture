# MangoShot v0.6.7 — Motion Typography & Clip Transitions (Alpha 1)

## Editable motion for text and callouts
- Entry and exit effects: None, Fade, Slide Up/Down/Left/Right, Pop, Bounce, Zoom Burst, Spin, Flip, Type In, and Spin Letters.
- Independently select entry and exit effect, duration and easing (Linear, Ease In/Out, Ease In-Out, Back).
- Dynamic numeric displays: Count Up, Count Down, Timer Up, Timer Countdown, from/to values, duration, decimals (0-3), prefix/suffix.
- Graphics retain existing fonts, style presets, layers, undo/redo, visual placement and editable timelines. Motion time is deterministic and relative to edited sequence time.
- Same Canvas rendering function runs in Program Monitor graphics and browser export.

## V1 opening transitions
- Select the SECOND or a later V1 clip, then expand **V1 · Opening Transition** in Properties.
- Single-stream cut treatments: None/Hard Cut, Dip Black, Dip White, White Flash, Wipe Left/Right, Iris Reveal, Slide In, Zoom Punch, Spin Reveal.
- Configurable duration up to two seconds and easing. Timing follows source-clip boundaries and clips as trimmed.
- IMPORTANT: These are **single-decoder cut treatments**, not two-source blended transitions or overlapping video streams. Original A1 audio remains at existing hard-cut boundaries. No crossfade is claimed.

## Save and undo
- Motion settings live on editable text/callout layers and are preserved in v1/v2 project JSON.
- V1 opening cut treatments are stored by adjacent source boundary and restored with the project.
- Undo/Redo snapshots include transition settings. Removing/reshaping cuts prunes unmatched cut-boundary transitions rather than applying them to arbitrary clips.
- Legacy projects with no motion fields remain readable and unchanged.

## Performance
- Effect sampling is deterministic by sequence timestamp, with no CSS-only illusions or timers affecting exported frames.
- No external assets, network calls, new browser permissions or video re-encoding during editing.
- Browser export continues to use MediaRecorder real-time capture; multi-source rendering and true crossfades need separate compositor work.

## Install and rollback
- Existing unpacked **v0.6.6-polish-alpha.1**: back up the extension directory and relevant recordings/projects, then extract the v0.6.7 root overlay into the SAME extension directory containing manifest.json. Reload the extension.
- Other versions / clean install: use the complete v0.6.7 extension ZIP. Do not overlay v0.6.6 incremental files onto older versions.
- Preserve local browser data. To roll back, restore the backed-up v0.6.6 extension directory and reload rather than uninstalling and clearing storage.
- Check SHA256SUMS.txt for each artifact.

## Validation / outstanding gates
- GitHub regression suite, new deterministic motion tests, source syntax checks and package ZIP CRC checks run in Actions.
- Required manual acceptance: Chrome, Edge and Firefox on Windows, Wacom stylus interactions, small viewport inspector layout, motion across edits, 24/30/60 fps export comparison, number/timer formatting, MP4/WebM codec availability and A1 audio cut behavior.
- Development prerelease only. Do not promote to stable or browser-store until the manual gates are complete.
