# MangoShot v0.5.7 — Public Preview 1

**Screenshot capture recovery + fully branded GitHub onboarding.** This preview supersedes v0.5.6-preview.1 for new installations; the prior version remains available as a rollback release.

## Capture reliability fix

- **Visible capture now takes the PNG directly from the toolbar action** while the browser's `activeTab` grant is present. Image Studio opens only after the PNG was validated and stored in browser-local IndexedDB.
- **Full-page capture runs while the original webpage stays active**; the background coordinator validates each frame, stores the completed bundle locally and opens Image Studio afterward. The editor no longer has to receive giant frame messages while inactive.
- **Incomplete or missing captures show explicit errors**, not an apparently successful empty canvas. Successful capture handoff is deleted after assembly.
- Added independent tests for popup capture, background frame routing, local PNG storage and the existing editor/PNG/PDF pipeline.

## Branding and documentation

- New gunmetal/charcoal/neon-lime SVG MangoShot banner with orange mango, centered record dot and white capture corners.
- Updated README with release downloads, full installation instructions for Chrome/Edge/Firefox, first-run workflows, update/recovery guidance and troubleshooting.

## Downloads and installation

- `MangoShot-v0.5.7-preview.1-Extension.zip` — extract and load the directory containing `manifest.json` in your browser.
- `MangoShot-v0.5.7-preview.1-Source-and-Tools.zip` — full source, test suite and optional cuts-only native helper.
- `SHA256SUMS.txt` — verify both archives.

### Notes and known limits

This is a **preview, not a signed/store-certified extension**. Cross-browser device-level screenshot capture is pending Windows testing. Browser-internal pages, restricted tabs, extremely large pages and some horizontally scrolling layouts are unsupported. Browser re-encoding can remain real-time. Firefox temporary add-ons disappear on restart; unpacked Chrome/Edge extensions update manually.

Never delete an older unpacked installation's local storage before exporting your recordings. For details, see `docs/RELEASES.md`.
