# MangoShot v0.5.6 — Public Preview 1

This is MangoShot's first **public GitHub preview**. It is a local-first screen recorder, full-page screenshot tool, Wacom-friendly annotation studio, and layered video editor for Chrome, Edge and Firefox.

## What's included

- User-initiated tab, window and screen recording with microphone/shared audio where the browser permits it
- PNG and PDF screen capture, scrolling full-page screenshots, pen, arrow, highlighter, text, and redaction tools
- Wacom pen input, camera zoom and optional linked-tab scrolling
- Clip Studio: Razor, Ripple Delete, sequence-time editing, graphics/callout layers, timeline undo/redo
- AutoCut: reviewable silence or low-motion suggestions, then gapless batch ripple deletion
- v0.5.6 sequence-sync improvements: thumbnails, audio waveform, and Program Monitor follow retained clips instead of original source timestamps
- Balanced and High-performance browser export quality profiles, plus optional Node/FFmpeg *cuts-only* helper in the source package

## Downloads

- **MangoShot-v0.5.6-preview.1-Extension.zip** — installable unpacked browser extension. Extract the ZIP first; open the extracted folder containing `manifest.json`.
- **MangoShot-v0.5.6-preview.1-Source-and-Tools.zip** — full source, tests, instructions, and optional desktop FFmpeg helper.
- **SHA256SUMS.txt** — checksums for verifying both archives.

## Installation

Chrome: open `chrome://extensions` → enable Developer mode → Load unpacked.

Edge: open `edge://extensions` → enable Developer mode → Load unpacked.

Firefox: open `about:debugging#/runtime/this-firefox` → Load Temporary Add-on → select `manifest.json`. Temporary Firefox installations do not persist between browser restarts; store signing has not been completed.

For upgrading an existing unpacked installation, save/export any unsaved recordings, replace the files in the **same directory**, then reload the extension. Different extension IDs/paths can isolate existing local IndexedDB recordings.

## Updating

Future preview versions will appear at [GitHub Releases](https://github.com/RawPowered/mangoshot-screen-capture/releases). Each release receives an immutable version tag, dedicated ZIP assets, checksums, and release notes. Unpacked installations **do not automatically update**. See [Update instructions](https://github.com/RawPowered/mangoshot-screen-capture/blob/release/v0.5.6-preview.1/docs/RELEASES.md).

## Current limitations

**Preview, not store-certified.** Automated regressions passed, but real Windows Wacom and browser screen-sharing/codec qualification remains pending. Browser edits and re-encoding may take real time; the FFmpeg helper renders cuts with audio but cannot compose graphics. Firefox and Chromium differ in system audio and captured-tab permissions. No auto-update mechanism is installed. Do not rely on interrupted MP4 fragments as a substitute for saved files.

No hidden capture or cloud upload is used.
