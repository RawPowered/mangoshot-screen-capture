# MangoShot v0.6.5 — Docked Media & Keyboard Workflows (Development Alpha 6)

**Baseline:** v0.6.4-visual-alpha.1. This is a development prerelease, not a stable browser-store release.

## Fixed workspace height / Media Bin
- The desktop editor now fills its browser viewport using a bounded CSS grid instead of auto-sized timeline rows that push the media import out of view. The monitor, edit timeline and pinned Media Library have explicit minimums and proportional space; no document-level scrolling is required for standard desktop editor viewports.
- The Media Library appears **directly below the timeline** with its own visible **Import** action, asset count, asset strip, preview (when space permits), staging/removal and relink actions. It uses the existing file input and local Media Bin; no duplicate import/storage path is introduced.
- Panels and the media asset strip scroll internally when needed. A collapse/expand button grants additional editing space without making Import inaccessible; dock state is persisted locally.
- On very short or narrow viewports a responsive compact/collapsed dock keeps controls accessible. Zoom and timeline scrolling remain supported within their panels.

## Tool icons
- Selection, Razor, Range, Text, Callout, AutoCut, Split, Ripple Delete, Trim, Undo and Redo use consistent vector (SVG) tool glyphs on the existing buttons, preserving tool identities and listeners.
- Icons include accessible names, tooltips, and dynamically updated key hints. Frame generation, waveform analysis and pinned import get smaller supporting icons.
- A keyboard icon in the upper menu bar opens the shortcut manager directly.

## Editable keyboard shortcuts
- One centralized shortcut dispatch replaces overlapping built-in handlers (but reuses original button actions). Default V/C/R/I/O/M; Ctrl+K split; Delete or Alt+Backspace Ripple; Ctrl+Z Undo; Ctrl+Shift+Z and Ctrl+Y Redo; Space and J/K/L transport; Shift+1/2/3 workspaces. Added T Text, G Callout, S Snap, Alt+I Media Import, Alt+B Media Library and ? Shortcut Manager.
- **Edit → Preferences → Keyboard Shortcuts** is now searchable, category-filtered, editable and keyboard accessible.
- Supports remapping, individual clear/reset, reset all, and JSON import/export, stored in extension-local localStorage. Rejects duplicate bindings and browser/OS-reserved key combinations. Prevents shortcut handlers from firing while typing into properties or dialogs.
- No requirement for remote account/sync and no changes to saved recordings, projects, captures or authorization scopes.

## Quality gates
Run all Node regression tests and v0.6.5 keyboard dispatch, collision and layout assertions, JS syntax checks, and verified ZIP CRC/archive member checks. Acceptance on Windows, Chrome/Edge, Firefox and Wacom with actual viewport resizing remains a manual gate before stable promotion.

## Installation
Overlay applies only over **v0.6.4-visual-alpha.1** unpacked extension. Back up your extension folder and export important recordings/projects, then extract the overlay directly into the existing directory containing `manifest.json`, overwriting files, and reload the extension. Older versions should use the complete v0.6.5 extension ZIP. Rollback by restoring the earlier files at the same path; do not uninstall or clear browser data.
