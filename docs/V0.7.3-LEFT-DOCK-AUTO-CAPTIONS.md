# MangoShot v0.7.3 — Left Dock and Auto-Caption Word Recognition

**Stage:** development preview. This branch is stacked on v0.7.2 (#34) and does not modify stable `main` or the published v0.6.18-alpha.2 extension.

## Scope

### User-reported issue and UI result

- Before: `#caption-studio-panel` lived inline above the timeline and could expand into most of its height. The screenshot showed small controls, heavy scroll, and lost visibility of edit clips.
- After: the left tool rail has a persistent **CC** button. It opens a professional Caption Studio dock with four controls tabs: **Transcribe**, **Cues**, **Style**, **Files**.
- On wide desktops, the tool is a real grid column next to the rail, preserving Program Monitor, Properties, CC1/V1/A1 timeline and media bin within the bounded workspace.
- On smaller viewports, it is an anchored panel and only the dock interior scrolls. Closing restores the full editor. Escape closes when no modal dialog is active.
- The CC1 sequence track remains available for selecting generated cues. Selecting a cue opens the Cues tab. The former full-height caption controls are no longer inline with the timeline.

### Actual automatically generated spoken words

**Primary:** packaged Transformers.js 3.8.1 + ONNX Runtime WebAssembly + open-source Whisper Tiny ONNX weights.

- User chooses **Generate Auto Captions** in the left Transcribe tab and explicitly consents to the first model download. The download source is the Hugging Face model repository `onnx-community/whisper-tiny.en` (English) or `onnx-community/whisper-tiny` (multilingual).
- Executable JavaScript and WebAssembly libraries are compiled **into the extension** at CI packaging time. No remote executable script is loaded at runtime.
- Model weights are fetched on consent and cached by the browser. Local audio is decoded in the browser from the current primary video. A fall-back local silent media-element decode may run in real time when `AudioContext.decodeAudioData` rejects MP4/WebM containers.
- A background module worker receives Float32 PCM at 16 kHz. The worker runs the model locally and requests `return_timestamps:'word'`; it returns timed words, not guessed evenly spaced cue timestamps.
- Automatically group several timed words into visible caption cues (default up to 4 words, 2.5 seconds); position cues on the edited sequence by mapping source audio timing through V1 retained segments. Deleted source intervals do not create subtitles.
- Preserve underlying per-word timestamps. The caption renderer highlights the word currently being spoken, with editable highlight color, optional highlight toggle, typography, outline, size and placement. Export continues to burn the same frames when requested; SRT and VTT sidecars remain available.
- Native on-device browser SpeechRecognition remains an optional, separately labeled fallback for browsers that implement it.
- No microphone capture is requested for Whisper transcription; no recording or PCM is uploaded to a service. Network access is restricted to model file hosts. No remote transcription API keys exist.

**Limitations:** Whisper Tiny may mishear speech and word timestamps are estimates from inference, not ground truth. Current implementation handles one primary source at a time, max 20 minutes / 300 MiB for full-buffer decode, with real-time capture fallback. CPU can be slow; WebGPU may be faster but is not universally supported. Browser memory limits and model download size vary. Model execution on real Firefox/Chrome/Edge targets is **not certified by unit and package tests alone**.

## Security, provenance, and license

- Dependency: `@huggingface/transformers@3.8.1` bundled as local `transformers.web.min.js` plus WebAssembly loader/WASM with SHA-256 inventory and third-party license notices.
- Model: `onnx-community/whisper-tiny.en` and `onnx-community/whisper-tiny`, ONNX conversion of Whisper Tiny, Apache-2.0 model weights at time of intake. Verify upstream licenses/revisions before shipping stable releases.
- Manifest MV3 CSP permits local Wasm execution via `'wasm-unsafe-eval'`, packaged workers from `'self'`, model-weight requests to specifically listed Hugging Face file hosts; it does **not** permit remote JavaScript execution or unrestricted external requests.
- Existing MangoShot Community Source-Available / no-resale LICENSE remains unchanged.
- Audio-transcription results are editable draft captions. No autosave, analytics, or uploads are introduced by this patch.

## Release gates and manual QA

| Check | Acceptance |
| --- | --- |
| Desktop 1920×1080 | Left CC rail button exposes a docked side panel; work area, monitor, timeline and image/audio clips remain visible; no page-level vertical scroll |
| 1366×768 and mobile-like narrow layout | Floating caption dock opens/closes without pushing timeline offscreen; internal panel scroll only |
| Tab interaction | Transcribe / Cues / Style / Files preserve input values, keyboard arrow navigation, focus and Escape |
| Default transcription | In Chrome/Edge, check consent, generate from WebM recording with speech and at least 30 seconds, verify actual detected words and timing |
| Browser limitations | On Firefox or unsupported WebGPU, choose CPU/WASM and try a supported recording; clear error and SRT/VTT fallback if decoder/model fails |
| Local model package | Inspect ZIP: actual local Transformers.js bundle, local ONNX .mjs/.wasm sidecars, hashes, licenses; no CDN script sources |
| Privacy | Browser network inspector shows only model-weight downloads; recorded audio and transcribed words are never POSTed to an API |
| Word highlighting | Play clips and confirm only the currently spoken word receives the highlight color; all other words retain base style |
| Edit sync | AutoCut/ripple/trim update caption and per-word start/end times; Undo/Redo and project save/reload restore timings |
| Export | Encode WebM and supported MP4; verify captions and word highlighting survive export; inspect AutoCut boundaries for black flashes or audio artifacts |
| Regression | All legacy recording/capture/image/video/UI/shortcut tests pass; browser-loading, model inference and Wacom still require user hardware |

## Build

CI: `.github/workflows/checks.yml`.
The feature branch runs `npm install --ignore-scripts`, vendors the pinned runtime, builds the extension with `tools/package-extension.py`, verifies required files and uploads the development artifact. Without `asr-runtime` packaged, archive validation fails.

**Do not merge into `main` or publish a stable extension solely because these static/regression tests pass.** Perform representative real-video/browser inference before release. The previous v0.7.2 draft and v0.6.18 official release remain rollback baselines.
