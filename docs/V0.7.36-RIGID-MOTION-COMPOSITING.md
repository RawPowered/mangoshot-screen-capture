# v0.7.36 Rigid Motion & Compositing
Qualified baseline 9e7a5b731800bc821f1210bd951ad9044d122306, run 45888510593, package artifact 15150971270. No stable merge.

## Rigid motion
- Each unified scene object can use either an existing deforming geometry track or a new rigid-body track. Rigid tracks hold the original mesh, including Bézier curvature and material; per-key quaternion orientation, XYZ translation (+/-6 world units) and reveal. Fixed custom pivot shared across the track (+/-3 world units), default node centroid, or set to first node. Shortest-arc SLERP avoids interpolation collapse; use intermediate keys for full turns. The renderer transforms positions and normals after mesh generation, retaining lengths and actual shared depth. Rigid motion is not a physics solver. No nonuniform scale, per-key pivot, or mixing deformation with rigid transform on a single object track yet. Removing rigid track restores source geometry; morph and rigid tracks can coexist on separate objects. Changing pivot affects all keys. Euler XYZ numeric inputs represent orientation; quaternion storage avoids Euler interpolation singularity. Direct preview drag rotates around world X/Y, Shift-drag translates in camera plane. No separate axis-ring interaction for rigid keys; prior static/pose gizmos retained.
- Mesh transforms use an allocation-free per-vertex matrix loop (no hardware throughput certification). Other rigid objects remain visible as transformed geometry in the pose editor; common preview evaluates every track. Static material/light retained in rigid tracks; prior pose tracks retain color/light interpolation. Source geometry unchanged.
## Scene foreground track
- Optional independent 2–12 normalized clip-local foreground keys with linear/smooth/hold timing. Four polygons per key, 3–64 vertices each; corresponding vertices interpolate. Different topology or invalid intermediate polygons hold previous mask. Key zero canonical scene mask. Draw/close/cancel, drag vertices, remove last/clear at selected key, sample reference at selected time. Preview guides excluded from export. Applies screen-space alpha cut to entire scene after shared 3D depth rasterization. Manual keyframing, not camera tracking, scene reconstruction or redaction. Up to eight object tracks + camera + mask = 120 keys.
- Sequence v11 required for rigid or shared mask tracks; previous v3–v10 remain readable. Image schema unchanged (static geometry). No new browser permissions or dependencies. Prior single-object motion and masks unchanged.
## Qualification
Unit tests include quaternion shortest arc and Euler roundtrip, pivot invariance, transformed vertices/normals and preserved edge lengths, mask interpolation, malformed data and v11 persistence. Browser test validates actual cross-object depth switch, mask alpha, UI pivot/rotation/translation, key insertion, vertex drag, inspector reopen and decoded encoded-video differences. All prior regression gates retained. Hardware performance, physical Wacom, Windows companion and Firefox manual validation remain outstanding. Automatic camera tracking, animated rigid materials, portable presets, GLTF/GLB import and transparent material sorting remain deferred.
