# MangoShot v0.7.22 — MangoEngine Raster Lab development preview
Base: 13aba07fa8a3e819011f94179b5a7b32ec0cb0ce. Retains v0.7.21 controls and previous test gates.

## Functionality
Raster Lab is accessible in Image Studio. It captures the current normal export composition (base plus ink, including redaction), not the original unredacted source. Compare original and processed draft; choose Auto (Rust/Wasm if bundled), JavaScript, actual-pixel center crop or fit, grayscale, 3×3 binomial Gaussian softness, 3×3 unsharp enhancement, and intensity. Export a separate full-resolution PNG. Layers, undo, standard PNG/PDF export, and capture are unchanged. This is intentionally an output processing studio, not a persistent editable filter or a replacement for the compositor. Spatial effects use a fixed one-pixel neighborhood; fit previews change sampling, use actual-pixel detail to inspect effect at export resolution. RGB filtering is alpha-weighted, retains the original alpha and does not create pixels outside transparency. Maximum 16 MP raster export (standard export unaffected). No source assets transmitted.
The worker loads only a packaged Rust ABI 1 module. JS worker fallback if missing/failed and sliced main-thread fallback if worker unavailable. One active request, timeout, cancellation and stale-result guard. Backend and round-trip diagnostic in dialog. Build locally with rustup target add wasm32-unknown-unknown and rustc --edition=2021 --target wasm32-unknown-unknown --crate-type=cdylib -C opt-level=3 -C panic=abort engine/mango-raster-v0722.rs -o mango-engine-v0722.wasm; package using python3 tools/package-extension.py --out dist --version v0.6.18-mango-engine-raster-preview.
Production preview CSP narrowly allows wasm-unsafe-eval for local Wasm; script-src self, object-src self; no new host or extension permissions. Rust source no dependencies, unsafe blocks, or imported remote modules.
