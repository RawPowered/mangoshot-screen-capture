# MangoShot v0.6.8 — Visual-First Inspector UX (Alpha 1)

## User feedback and interaction goal
The prior narrow Callouts panel was dominated by a long linear stack of numeric motion controls, requiring extensive vertical scrolling. This pass makes the frequently used choices visual, organized and discoverable without discarding precise configuration.

## Focused navigation
- Main Properties tabs (Clip, Callouts, Camera, Voiceover, AutoCut) occupy a single compact row instead of two rows.
- **Callouts** has four local sections: **Design | Motion | Numbers | Advanced**.
- **Clip** has **Edit | Transitions**. Opening V1 transitions no longer appear underneath Callouts.
- Child tab state persists locally; keyboard ArrowLeft/ArrowRight/Home/End switches tabs, with roles, selected state and focus.
- Switching settings sections returns the property scroll to the top, while preserving the rest of the desktop workspace.
- Layers remain within one short expandable tray above Callouts navigation. No duplicate layer model or reparenting of source media.

## Visual-first controls
- Entry and Exit use one shared visual gallery with **Essentials / Viral** filters. The cards write through the original v0.6.7 select elements and their change listeners; original event transactions remain undoable.
- Duration uses a slider and readable seconds; quick Snappy, Natural and Cinematic buttons reduce exact-value entry. Easing, type and full durations remain in **Fine timing & easing**.
- Numeric overlays offer visible modes: Static, Count Up, Count Down, Timer Up and Countdown. Quick-start setups: 0→100%, $0→$10K, 30-second countdown and 2-minute timer. A live sequence-time sample and duration slider are displayed; precision, prefixes, suffixes, endpoints and long durations remain in **Exact values & formatting**.
- Transitions have their own visual cards and short timing slider. Use a selected second or later V1 clip; no cut effect is shown as a true two-source crossfade.
- **Preview animation**, **Preview counter**, and **Preview cut** seek the existing Program Monitor to the actual effect timing and play from there. No CSS-only export imitation.
- CSS-only thumbnails animate on hover/focus/selection, respect reduced-motion settings, and do not change rendered export pixels.

## Engineering and preservation
- Original input IDs, event handlers, MangoMotion/MangoGraphics/MangoClipView source of truth, project JSON, undo/redo and renderer remain intact.
- Corrected v0.6.7 transition-panel insertion after the Properties DOM was reparented.
- The patch only touches the existing editor interface, one motion UI integration point, manifest and new UI assets. No recorder, screenshot, storage or browser-permission changes.
- Media export remains browser-real-time and V1 effects remain single-decoder cut treatments.

## Install
**Overlay** only for an existing **v0.6.7-motion-alpha.1** unpacked extension. Back up the folder, recordings, voiceover sources and edit projects. Extract files into the **same folder containing manifest.json** and reload the extension in Chrome/Edge or Firefox temporary extension debugging. Do not install overlay over older versions.

**Full ZIP** for new installations/older baselines. Rollback by restoring the prior extension folder and reloading without clearing browser-local storage.

## Validation gates
- All existing tests plus visual-inspector structural regression, Node syntax checks, full ZIP and overlay member/content/CRC/hash verification in GitHub Actions.
- Still requires hands-on Windows Chrome/Edge/Firefox and Wacom review of 280–420px inspector widths, short viewports, keyboard focus, selection switching, clip and callout preview/export parity, and persistent tabs.
- Development alpha only; do not merge into stable/browser-store until manual runtime acceptance.
