## Pixel selection contract
- Dedicated Carbon modal, independent of existing object marquee. Rectangle, ellipse, click polygon (close button, Enter or double click), freehand lasso. Ordered replace/add/subtract/intersect operations, select all, deselect, undo selection step, final inversion, 0–64 source-pixel Gaussian feather, enable toggle. Preview dims nonselected pixels and shows selection alpha; dashed lines show input region outlines, not the exact final Boolean contour. Scaled preview approximates full-resolution feather/antialias; optional actual layer compositor preview.
- Two explicitly separated scopes. Composition scope uses normal flattened source+ink including visible redactions; export PNG at full original canvas dimensions with transparent pixels outside selection. Max 16 MP selection export; ordinary exports unchanged. Does not modify the document or export the underlying unredacted source. Inspect shared PNG for visible redactions.
- Source scope only on one visible unlocked imported image. Draw relative to raw original asset (private view, may expose original pixels); normalized regions persist independently of layer transforms. New selection mask is a non-destructive geometric alpha intersection AFTER legacy brush masks and quick-cutout matte, BEFORE geometry/material/outer effects, without replacing or clearing existing masks. Disabled masks retain edit recipe. Clear removes only the selection mask. Apply through existing revision-checked Layer Studio transaction, one undo/redo step. No destructive pixel editing.
- Native .mangoimage v6 stores selection recipes, previous v1–v5 readable. 16 regions, 2048 vertices per polygon/lasso, 8192 points per selection, aggregate 100k selection points; per-source active mask 9MP, 18MP active mask budget/12 layers (counted per layer because masked canvases are not shared); existing legacy mask composite caps still apply. 16MP composition export. Canvas2D feather requires filter support. No added permissions, cloud or dependencies.
- Full-canvas selection is currently modal-based, not a global persistent marching-ants selection. No true interlayer clipping mask (alpha of a different live layer), arbitrary stack-position adjustments, retouch, crop/resize/resample or GPU rendering yet. Selection masks are NOT security redaction or interlayer clipping. Editable files contain original assets and should remain private.
