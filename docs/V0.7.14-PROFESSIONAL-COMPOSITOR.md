# Professional Compositor 0.7.14 — development preview

Baseline: qualified Cinematic Studio commit 46304ed07b4b9100455a15ccd15168e9f54387f2. One shared modal in Image and Clip Studio. The same non-destructive edit history and layer model are retained.

- Ordered effect stacks: up to 8 enabled/disabled adjustments, reorder, remove, 10 looks including silver, cinema contrast, editorial, warm, night and soft focus; 20 locally saved custom stacks. Exposure, contrast, saturation, sepia warmth, hue, monochrome, soft focus and invert. These are whole-layer Canvas2D filters on an isolated transparent raster, combined with existing appearance controls. Protected redaction/eraser and locked layers are excluded. Image filters affect annotation layers, not the original screenshot.
- Clip graphic keyframes: up to 32 unique positions in normalized layer duration, relative X/Y offsets, uniform scale, rotation and opacity multiplier, with linear/ease-in/ease-out/ease-in-out/hold interpolation. Existing entry/exit motion and fades remain composited. Trim/retime changes relative keyframe time; direct canvas dragging of keyframed graphics is disabled to prevent editing the wrong transform. Selected graphic hit bounds approximate the keyframed box, not every animated glyph or shadow.
- Source color grading: ordered stack applied after source zoom and cinematic cut rendering, before cursor and graphic overlays. Current decoded source-frame draft preview. Entire retained source, not individual V1 segment grading. Undo, original-byte save, V1/V2 project round-trip, sequence automation/checkpoints and reviewed still-frame pipeline preserve source grade. Native cut-only export refuses source grading. Browser export preflights filter support and aborts on compositor frame errors.
- Actual Canvas2D grayscale probe gates support; unsupported environments reject active filters rather than silently dropping them. Scratch raster capped at 33 million pixels per buffer; actual peak memory includes the existing cinematic and graphic buffers. No independent source clips, arbitrary effect plugin execution, true isolated folder compositing, GPU/native acceleration, HDR/LUT pipeline, bevel or procedural metallic shaders. Image project persistence remains session-local. Firefox/Edge/4K performance and hardware tests pending.
- Existing tests retained; new pure and Chromium tests cover stack validation, actual image pixels, local preset save, decoded graded WebM, keyframe interpolation and animated renderer output, project serialization, undo and compact bounds. No stable release promotion or permission changes.
