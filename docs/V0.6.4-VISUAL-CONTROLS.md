# MangoShot v0.6.4 — Visual-First Camera & Clip Editing Alpha 5

This development alpha builds on v0.6.3 Interactive Camera HUD. The published recorder and screenshot engines remain unchanged.

## Fixed: blank zoom preview
The previous HUD assigned `canvas.height` on every refresh AFTER drawing the frame. Updating canvas dimensions clears the bitmap, which directly caused the blank view. v0.6.4 resizes only if the source aspect ratio changes, BEFORE drawing, then renders a local decoded video frame. If it has not decoded, the panel shows an explicit loading/status message rather than pretending an image is present.

## Camera Properties
- Draggable camera rectangle with four corner resize handles; zoom changes between 100% and 500% while preserving source aspect ratio and the opposite corner.
- Fast 100%, 150%, 200%, 300% buttons, compact Set In at playhead and Set Out at playhead actions, and Apply Camera Move. Original zoom and return controls remain available.
- Coordinates, numerical zoom and ease, and exact time inputs are behind **Advanced: Precise zoom, coordinates and easing**; no longer crowd the primary workflow.
- Local frame preview refreshes on the video decoding events and seeks, with compatibility for requestVideoFrameCallback and a normal event fallback.

## Clip Properties
- Visual miniature timeline with available generated source thumbnails, selection shading, playhead, and draggable In/Out grips. These call the existing editor setRange and seekOutput operations, so the actual V1/A1 Razor/Ripple/Trim decisions remain authoritative.
- One-click Set In and Set Out at playhead; numeric values and source container information are retained in the **Advanced** drawer.
- Split, Ripple Delete, Trim, Undo, Redo move into the left tool rail as icon actions. Restore source and Play edited sequence remain in the Edit menu. Underlying button IDs, enabled states, handlers, and existing keyboard shortcuts remain unchanged.
- Mini filmstrip reflects regenerated thumbnails after edits. It is a small navigator, not a separate media track.

## Release gates
Full Node regression suites and new normalized HUD rectangle / canvas redraw / UI structure tests; syntax and ZIP CRC validation. Real Windows, Chrome/Edge/Firefox and Wacom testing is still required. This remains an alpha, not a signed browser-store or stable release.

## Installation
Incremental overlay requires v0.6.3-hud-alpha.1 unpacked extension (manifest 0.6.3); back up the extension directory and export projects/recordings, then extract this root-level overlay into the **same folder** containing `manifest.json` and reload. Use the complete extension ZIP when updating an older version. For rollback, restore the backup in the same path without uninstalling or clearing browser data.
