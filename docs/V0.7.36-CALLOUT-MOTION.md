# v0.7.36 Callout Motion Studio (development)

Base d12d7e25b9c1bb23340f435f842ffa41a7546581 (v0.7.35 Callout Designer). Separate from the parallel v0.7.35 precision 3D modeling branch. No main merge or stable promotion.

The Callout Designer now adds keyboard-accessible rotary dials, fine Shift-drag, numeric inputs and sliders, and double-click reset. The new Keyframes tab stages independent property tracks for X/Y, width/height, opacity, rotation, glow, stroke, fill opacity, text scale, spotlight dim and progress. Two to 12 keys per property, up to 12 properties, fixed endpoint times, 1% key separation, bounded values. Linear, smoothstep, ease in/out, hold and monotone cubic Bezier (numeric controls) are outgoing interpolations. Graph shows sampled property, key positions and preview playhead. Select and seek keys, add at playhead, edit time/value/easing, delete interior keys or remove tracks. Removing a track restores its static property. Static values are not silently overwritten by key edits.

Drift/rise/arc presets explicitly replace only X/Y tracks (confirmation if present). Drawn motion path and keyed bounds use evaluated geometry. Drag/resize/nudge in Keyframes mode creates appropriate pose keys at the current preview fraction. Static canvas manipulation is blocked for animated geometry outside Keyframes mode. Preset entrance/exit animation still composes with keyframes; clip fades and track opacity apply once. Motion is normalized to clip duration; moves preserve keys and trim retimes them rather than trimming source-space keys. No source tracking, arbitrary vector path tangent handles, 3D changes, magnification lenses, viewer-clickable interactions or additional tracks. Native v11 only when keyframes are added; v3–v10 remain readable; v11 remains after removing motion. Existing G2/G3 overlap limit remains. No permissions or cloud services added.

Unit gates test bounded schema, monotone easing, independent channels, pose paths, locks, timeline movement and round trips. Browser gate tests dial input/reset, property editing, graph/seek, native saves, actual preview pixels and actual WebM pixels at multiple timestamps. CI and manual browser/hardware certification must be reported separately.
