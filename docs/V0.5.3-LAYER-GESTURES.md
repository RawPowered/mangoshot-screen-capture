# MangoShot v0.5.3 — Graphics direct manipulation

This update implements professional, non-destructive graphic timing and stacking with Wacom Pointer Events. The original video remains unchanged.

## G2/G3 timeline
- **Drag clip body** left/right to move a graphic while preserving its duration.
- **Grab the left or right colored edge** to alter its In or Out point. An operation is recorded as **one undo step** on release, not for every pixel moved.
- **Drag the clip vertically** from G2 to G3 (or reverse) to change its track, with the target lane highlighted. G3 renders above G2.
- **Magnetic snap ON by default** to timeline start/end, other graphic edges and the playhead; click Snap to toggle; hold Alt during a drag to bypass.
- **Key nudge** while a graphic clip is focused: Left/Right moves one frame (Shift=1 second); Alt+Up/Down changes stacking within its track.
- Pointer capture and dashed drag-ghost keep the operation visible without creating duplicate content or editing the underlying footage.

## Layers / Program Monitor
- Drag the dotted handle in the graphics list to place a layer above another. Dropping onto a row also takes its G2 or G3 track.
- Bring Forward / Send Back now change the actual array draw order (previous code called a missing method).
- The selected graphic can be dragged anywhere in the visible video frame; drag the lower-right handle to change width/font size with the pen or mouse. The inspector retains precise X/Y, width, font and start/end controls.
- Selected graphic feedback never appears in the final exported pixels.

## Correctness and limitations
- Video cuts and ripple edits continue to retime graphic layers using sequence time. No source pixels are changed by these operations.
- The project JSON stores the ordered layer array and its times/track; reopening restores the ordering.
- G2/G3 are graphics, not separate video streams. No position animation keyframes or transitions are included yet.
- Canvas text rendering remains browser-font dependent; the exporter and preview use the same graphics compositor.
- The minimum timeline graphic duration is 0.08 seconds while dragged; existing v0.5.2 projects with shorter clips remain readable but must be extended before dragging.

## Release test plan
1. Add two graphics on G2 at different times, then drag a clip body by 5 seconds; check the resulting time and saved project file.
2. Pull both handles; ensure duration changes without moving the opposite edge and undo restores the original interval.
3. Move a graphic from G2 to G3 and verify which graphic appears on top when their times overlap.
4. Reorder two G2 graphics in the left panel, and test Bring Forward/Send Back, undo and project save/reopen.
5. Move and resize a text box in the Program Monitor with the Wacom pen; verify the final render matches the preview, excluding selection handles.
6. Split and ripple-delete video underneath graphics, then validate the shifted graphic start/end points.
7. Confirm screenshot capture, recording reliability and unedited instant-save still pass.

This is an unpacked test-drive build, not store certified. Actual Windows Firefox/Edge/Chrome and Wacom QA remains required.
