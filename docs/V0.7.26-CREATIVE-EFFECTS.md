## Appearance contract
- Single visible unlocked eligible image layer. Dedicated Carbon modal with current/draft real composition previews, tabs for gradients, shadows/glows, existing materials. Explicit Apply/Cancel, one existing Layer Studio undo transaction. No independent document model.
- Linear and centered radial alpha-preserving overlays, 2–8 strictly ordered stops (fixed endpoints), draggable inner stop handles, exact positions, RGB and individual alpha, overall opacity, angle. Six curated presets including gold/silver/carbon/glass sheen. Existing material strength/depth/light angle/colors reused; not physically simulated refraction or new 3D bevel. Gradient follows rotated world-aligned bounds and overlays the filtered material before outer effects.
- Up to six ordered independent drop shadows and outer glows: RGB, opacity, blur, X/Y, enable, add/remove/reorder. Uses same final alpha mask for each underlay, composites source once, applies legacy blend once. When creative effects active, legacy shadow/glow becomes first underlay using Canvas2D blur; exact old shadow softness may differ from native shadowBlur on that path. Legacy-only layers stay on the original painter. Glow is zero-offset. No inner shadow, knockout/spread, physical lighting, or arbitrary blend per effect. Transparent pixels remain transparent for the gradient; shadows intentionally extend outside alpha.
- Shared synchronous three-buffer scratch limited to 9 MP per canvas (includes UHD 4K) and up to 64 active creative-effect layers. Existing legacy renderer and Raster Lab unchanged. Canvas2D blur support required for enabled blur. No claim of measured performance. Group scratch and existing material/filter buffers also consume memory.
- Native format v4 persists creative effects, existing v2 composition, v3 brush profiles; previous versions readable and saved when compatible. Existing project schema, protection, memory checks and revision guards retained. Copy/paste style includes creative effects. Layer stack adds expandable appearance labels and effective alpha-mask thumbnails for imported images with an editable mask or cutout (white visible, dark transparent; no source RGB in mask thumbnail).
- Keep all previous automated gates; new model tests and real extension browser pixel tests for multi-stop gradient and overlapping shadows, protected redaction, undo/redo, exact v4 reopen, mask thumbnail, modal compact size. Manual Firefox/Edge/Wacom, 4K stress, visual inspection pending. Editable Rust filters, clipping masks, complete group tree and arbitrary adjustment z-order remain separate work. No production manifest permission changes or stable release.
