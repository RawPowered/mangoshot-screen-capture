# MangoShot v0.6.18 — Layer Clipboard, Alt-Drag Cloning and Layer Styles

## Scope
Image Studio layer UX only. Existing capture (visible/full/area), local Quick Copy, Wacom pressure/erasers, Clip Studio and PNG/PDF export are preserved.

### Layer clipboard
- Select an editable layer by canvas or Layer Stack. Ctrl+C copies, Ctrl+X cuts, Ctrl+V pastes within this running Image Studio tab. The internal structured layer clipboard is separate from Copy Image, which still writes a full annotated PNG to the operating-system clipboard.
- Copy works on locked layers; Cut, transform, Clone and Paste Style respect layer locks. Paste makes a new unlocked layer above the selection with a distinct offset. Each paste is a separate undoable action.
- Imported image layer data references the current tab's image asset registry. This is not an inter-tab clipboard or a generic OS clipboard serializer.
- Copy Style and Paste Style transfer opacity and appearance without changing the layer's geometry or image data.

### Transform and reordering
- Select and drag editable text, images, vector shapes, pen/highlighter paths and other annotations directly on the canvas.
- Alt+drag clones exactly one unlocked layer after movement begins. A mere Alt+click only selects; Ctrl+Z removes the clone and restores original.
- Arrow keys nudge a selected layer one source pixel. Shift+Arrow keys nudge ten pixels. These shortcuts work while the Layers selection row button retains focus, but never during live text editing, IME composition or input fields.
- Layer Stack includes drag grip handles for reorder with single-step Undo. Move Up/Down buttons remain available.
- Background screenshot is not a layer, and is never modified by layer transforms.

### Layer appearance
- Live Opacity from 0 to 100 percent, one Undo per continuous gesture.
- Presets: None, Shadow, Glow, Floating and Crisp.
- Custom: None/Drop Shadow/Outer Glow, color, blur, horizontal and vertical offsets, and Normal/Multiply/Screen/Overlay/Darken/Lighten composition.
- Stored as per-layer structured attributes, not CSS overlays; one Canvas painter is shared by editing preview and exported annotated PNG/PDF/clipboard.
- Blend modes operate against other annotations in the overlay, not as full Photoshop-style blending against the unmodified screenshot. Existing text/vector specialist styles remain.
- Eraser strokes and redaction annotations intentionally bypass appearance effects. Visual redaction is not certified irreversible redaction.

### Shortcut manager
New Image Studio defaults: Copy Ctrl+C, Cut Ctrl+X, Paste Ctrl+V, selected-layer nudge by arrows, Shift+arrows for 10px, Copy Style Alt+Shift+C, Paste Style Alt+Shift+V. Previous v0.6.17 saved profiles migrate with new actions receiving safe defaults. All actions remain customizable in the established menu.

## Automated tests
Existing capture, editor, Wacom, video, keyboard and menu regressions are retained. New tests cover layer geometry, non-mutating internal clipboard, selected hit-testing, Alt-drag clone, arrow nudge, style compositing, duplicate-binding rejection, ZIP consistency and strict overlay source diff.

## Browser acceptance before stable
Test copy/paste across text/image/vector/pen; Alt-drag with mouse and Wacom; selected shortcuts vs typing text; drag reorder; opacity, blur and effects; Undo/Redo; PNG/PDF and clipboard export parity; zoom fit and 100 percent; Chrome, Edge and Firefox. Manual acceptance is pending, so this remains an alpha release.

## Installation and rollback
Overlay requires an unpacked v0.6.17-shortcuts-alpha.1 extension. Back up the folder containing manifest.json, extract overlay there and reload at chrome://extensions, edge://extensions or Firefox about:debugging. For earlier versions use the full extension package. Roll back by restoring v0.6.17; do not uninstall or erase extension storage holding local recordings. No new permissions, cloud APIs, assets or telemetry.
