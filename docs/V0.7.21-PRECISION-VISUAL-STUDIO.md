# Precision & Visual Effects Studio — v0.7.21 development preview

Based on v0.7.20 Carbon Image Studio hotfix aec999301f5efababa8ec6f2d4855be89d641bbc. Carbon stylesheet remains final; existing theme gate is unchanged. The original v0.7.20 run failed on stylesheet order, so this branch is not a qualified release until full tests pass.

- Precision Studio gains expandable advanced appearance controls: HSV hue wheel, saturation/value field, native color picker, hex and numeric H/S/V; linked shadow offset XY pad with exact numeric input; real renderer-generated material preset thumbnails, two-color material editing, depth, intensity and angle.
- All values modify only the dialog draft. Revision-checked Layer Studio apply commits a single transaction. Same renderer used for preview and export; full-resolution material budget preflight. No arbitrary gradient stops, actual background refraction, image-level grading, or new raster effects in this pass.
- Persistent layer dock gains pointer and keyboard resizing (25–60% preference, subject to compact layout bounds). No new document ownership.
- Browser regression checks actual extension, draft isolation, material and shadow changes, single-step undo, Escape, dock resizing, compact viewport. Full existing unit/browser suite remains mandatory.
- Rust experiment v0.7.20 run 45860461149 passed both native tests and Node Wasm parity. 1080p median JS 6.90 ms/Wasm 4.58 ms; 4K JS 26.81 ms/Wasm 20.62 ms; includes copies. These are runner-specific grayscale results, not compositor performance.
- Add isolated real Chromium extension worker fixture using locally compiled Wasm, narrowly scoped wasm-unsafe-eval CSP, transferable RGBA buffers, malformed-input rejection and byte parity. Fixture is generated in a temporary directory and never shipped. Production extension manifest, permissions, renderer and licensing remain unchanged. GPU, Firefox, Edge and Wacom qualification pending. Browser worker benchmark is a feasibility gate, not production adoption.
- Pressure curves, actual per-layer thumbnails, hierarchical compositing, arbitrary multi-stop gradients and durable image documents remain separate future work.
