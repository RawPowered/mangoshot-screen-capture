# MangoShot v0.6.9 — Premium Studio, Creative Resources & Full Branding (Alpha 1)

## What changed

### Fully branded application
- The **user-supplied** glossy MangoShot Neon Tech wordmark is the master for the optimized transparent WebP wordmark.
- The user-supplied glossy mango recording mark is the master for transparent compact branding and manifest PNG icons at 16/32/48/128 pixels.
- Shared graphite, polished-silver, mango-orange and neon-lime design tokens style the popup, recording screen, image annotation, Clip Studio and Resources.
- The extension popup no longer uses an emoji logo. Studio headers no longer use the generic M as their primary mark.
- No generated logo, watermark or badge is rendered into user videos or screenshots.

### Premium Studio — first functional collection
- 24 curated editable compositions in Titles, Subtitles, Callouts and Text: six per group.
- Each has deterministic local Canvas material styling and preset entry/exit animation. Materials include glass-like gradients, metallic reflection, chrome, aurora, holographic and editorial treatments.
- Premium titles and callouts can insert paired primary/detail text graphics with one Undo snapshot. All layers retain timeline editing, text editing, and original project save/restore contracts.
- Local Canvas preview cards, categories, search, favorites, customizable intensity/accent and one-click insertion.
- **Alpha quality boundary:** these are premium Canvas2D material treatments, not true filmed reflections, background blur/refraction, physical PBR textures, real tracked callouts or GPU shader transitions. WebGL-backed materials and a more advanced multipass compositor remain future milestones.
- Selecting a premium composition adds editable local graphics to the current sequence; it does not alter the source recording bytes.

### Creative Resources
- Separate **Resources** navigation entry across workspaces and the popup.
- Resource cards provide ordinary external links to providers for photos/video, fonts, materials, audio and icons.
- Provider categories, local search, local favorites, links to provider license pages and licensing caution.
- No iframe, scraping, API keys, remote asset auto-download or additional extension host permissions.
- Imported files continue using the existing local Media Library. Secondary V2 media staging does not yet imply composited export.

## Installation
**Full package** for fresh installations or older versions: download the complete extension ZIP, unpack, load unpacked extension from the folder containing manifest.json.

**Overlay** ONLY for an unpacked v0.6.8-visual-alpha.1 installation:
1. Preserve important recordings and project JSON; back up the entire existing extension folder.
2. Extract the v0.6.9 overlay into the SAME folder containing manifest.json, overwriting matching files.
3. Confirm assets/mangoshot-wordmark.webp and assets/mangoshot-icon.webp exist, as well as new premium and Resources scripts.
4. Reload under chrome://extensions, edge://extensions, or Firefox about:debugging.
5. Test Capture, Record, Annotate, Clip Studio, Premium Studio and Resources.

For rollback restore the v0.6.8 backed-up extension folder and reload. Do NOT uninstall or clear browser-local recordings.

## Validation and safety
- Automated test suite, source syntax validation, premium deterministic Canvas tests, brand asset PNG/WebP integrity, resource link safety, project read/write and legacy regressions.
- Complete and incremental ZIP checked for member list, content hashes and CRC.
- No browser permission additions, no third-party injected script or iframe, no remote texture fetches.
- Manual browser/Wacom visual QA and 1080p/4K export comparisons remain necessary before stable promotion.
- This prerelease does **not** claim production-grade WebGL shaders, optical refraction or true two-source video blending.
