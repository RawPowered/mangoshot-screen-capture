# v0.7.35 Precision 3D Modeling
Qualified baseline 430257da7a319dcbbaa2bcc41fbeb9f6cb03fa44, run 45879423284, package artifact 15146763276. No stable merge.

## Geometry
- Arrows, swept tubes and ribbons have an explicit cubic Bezier mode with independent relative XYZ incoming/outgoing tangent offsets per node. Legacy Catmull-Rom or straight paths remain unchanged unless explicitly converted; mathematical conversion preserves the original curve. Cubic segments use 16 sampled intervals vs legacy 12, so rasterization/arc-length approximation can differ slightly after conversion. Exact De Casteljau subdivision inserts a node without altering the mathematical path; deletion joins neighboring segments and may change curvature. Max 12 nodes; offsets bounded to +/-3 world units per component. General self-intersection/cusp solving is not implemented.
- Select node or incoming/outgoing tangent, edit numeric world XYZ, drag selected tangent in view plane or along XYZ gizmo, optionally mirror the opposite handle. Translation preserves relative handles; rotation and uniform scale transform offsets along with anchors. Existing front/top/right and perspective views, material controls and depth renderer retained. Guides not exported.
- Fixed curve topology across motion keys; handle offsets interpolate with the same easing as anchors. Both older single-object and independent scene object tracks support animated handles. No automatic conversion of existing animation. Image v12 and sequence v10 when Bezier geometry exists, older projects remain readable. Quaternions and shared-scene keyed masks deferred.

## Local presets
- Three built-in object routes and one two-object scene. Save up to 16 user object and 16 user scene presets per extension origin in validated local storage, shared by Image and Sequence studios. Explicit save/load/delete, duplicate names rejected, bounded JSON size; malformed storage fails closed, no silent overwrite. No new browser permissions, dependencies or network requests. Browser profile/extension reinstall can clear local data; project files remain portable.
- Object presets contain only validated geometry/material and retain destination camera/foreground mask on loading. Scene presets contain camera, names, geometry and visibility but no source image/video, foreground masks, motion, or locks. Instantiate new IDs, unlock all; replacing a scene draft with locked objects is blocked. Applying a preset changes the draft only; editor Apply commits. Saving/deleting local library entries is immediate and independent of editor cancel. Animation topology lock disables preset edits. Geometry and scene presets do not save motion or import/export preset files.
- Tests cover exact cubic conversion/split, transformed handles, interpolation, incompatible topology, native schema and validation; actual pointer Z tangent manipulation, image v12 pixel reopen, local cross-editor presets, new scene IDs, tangent animation and encoded video. All previous regression gates retained. Manual hardware performance and Wacom validation still needed.
