# MangoShot v0.6.3 — Interactive Camera HUD and Visual Typography (Development Alpha 4)

**Built from:** v0.6.2 Focused Workspace Alpha 3. Public stable/browser-store certification has not been performed.

## Camera: drag-to-frame HUD
- Small in-Properties preview displays the **current local video frame**; it never uploads media.
- A lime rectangle depicts the proposed camera viewport, and a dashed outline depicts the actual keyframed viewport at the playhead. Drag inside to pan, or click to recenter. Arrow keys move the selected viewport (Shift = larger steps).
- Focus X/Y fields and the draggable viewport update together, using the same mathematical transform origin as the video renderer.
- Set **Zoom In** and **Zoom Out** sequence times; **Apply In → Out** adds both keyframes as one undoable edit. Existing keyframes can be selected, repositioned, and updated in Properties.
- Scale 100% correctly fills the full frame and disables pointless panning. Local still-frame samples are drawn only when Camera Properties is displayed.

## Text and callouts
- Eleven preview cards use the same style metadata as MangoGraphics canvas output; selecting a card updates the actual graphic layer (or the default creation preset when nothing is selected).
- Seven visual font previews, with corresponding browser/system font stacks supported by the canvas compositor.
- Quick editing: text entry, A− / A+, bold weight, left/center/right alignment, duplicate, delete, and text color.
- Technical fields move to **collapsible drawers** for Typography, Layout/Pointer, Appearance, Timing and Layer actions. Existing element IDs and change handlers are preserved, including original undo history.
- Preset gallery and font choices remain keyboard reachable with accessible names and selected state.

## Installation
- **Overlay:** for installations currently on v0.6.2-ux-alpha.1 only. Back up and export valuable recordings, then extract the overlay over the same extension directory containing `manifest.json`, and reload.
- **Full extension:** use the versioned full package if the current installation is another version.
- Known limits: secondary imported video/images remain staging-only; voiceover source is session-local until downloaded; browser export can be real-time.
- Cross-browser Windows/Wacom runtime validation is required before considering this stable.
