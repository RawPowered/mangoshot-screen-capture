# Cinematic Studio 0.7.13 — development preview

Baseline: Layer & Effects Studio 585c32d857147464fbb9920c07e6001709516e34. This pass fixes modal Escape/reopening and extends the existing appearance modal with batch graphic entry/exit motion, six combinations, custom duration/easing and scrub preview. Existing numeric motion remains unchanged.

Cinematic Studio adds 10 two-decoded-frame cut transition presets: cross dissolve, four wipes, iris, left/right push, zoom dissolve and whip pan. The library thumbnails are illustrative; actual preview decodes the user's source video. A cut and preset, duration/easing, explicit source-handle consent, draft preview preparation, and Apply are required. The transition preserves existing sequence duration and audio cut timing. It uses source handles before/after the adjacent retained clips; it can expose trimmed-out source material and is opt-in. Project validation rejects missing handles, missing boundaries and excessive transition samples. Existing single-decoder cut treatments remain unchanged. It does not implement independent source clips or arbitrary keyframe tracks.

Rendering uses two actual source frame sequences prepared locally at 24 samples/second (nearest sample), with a 96 MiB nominal RGBA raster budget, maximum 180 frame pairs, dimensions capped at 1920x1080 and reduced as needed; reject if resolution falls below the configured minimum for larger sources. The main source audio remains unchanged and graphics still render after the transition. The same prepared frame cache serves Program Monitor and browser export; export preflights all transitions or aborts. Proposed frame and reviewed bridge image use an independent exact two-frame decode. Native FFmpeg cut-only export rejects transitions rather than ignoring them. No permissions changed. Browser export is real-time and not frame-exact; 4K/long sequences, low-memory devices, Firefox/Edge and real export decode are separate qualification tasks. Cursor effect overlays retain the existing transition exclusion.

The new pure and real browser gates test all preset compositors, handle constraints, actual decoded red and blue source pixels, project round trip, no duration change, undo/redo, modal bounds and graphic batch motion. Previous suites remain required. Not a stable release.
