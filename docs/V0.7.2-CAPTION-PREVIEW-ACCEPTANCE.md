# MangoShot v0.7.2 — Caption Studio and Preview Continuity

**Status:** development preview only. Source branch: `feature/v0.7.2-captions-preview-continuity`.
Based on the current MangoShot `main`. Does not replace published `v0.6.18-layers-alpha.2`.

## Problem reports reproduced in source

1. **Program Monitor disappears after selecting V1/A1** following thumbnail and waveform generation. The old `paintPreview()` cleared its canvas unconditionally while selection initiated a decoder seek; it did not always paint the underlying video frame into its overlay.
2. **Millisecond black blips after AutoCut**. The old export paint loop filled the canvas black on *every* animation frame. Whenever the decoder had no frame ready during a source jump, that black fill was encoded despite the edited sequence having no logical gaps.

Changes: the Program Monitor now retains the last composited frame while seeking and repaints on frame readiness; the export canvas is cleared initially only and then retains its previous decoded frame during source jumps. Playhead logic preserves sequence position while seeking, including exact cut boundaries.

**Important limitation:** these changes eliminate unnecessary black clearing and provide continuity during decoder stalls. They do not guarantee true frame-accurate output or sample-accurate audio joins with a single HTMLMediaElement decoder. Physical browser/codec and end-to-end encode tests are required before a zero-black-frame claim can be made.

## Caption Studio capabilities

- Independent CC1 cue track, select/edit/delete/add, sequence-based In/Out, title text and cues.
- Local SRT and WebVTT import and export, no external calls.
- Five caption presets: Classic CC, Creator Bold, Editorial, Clean, MangoShot.
- Custom font, size, position, text/outline color, plus style preservation in project JSON.
- Optional Canvas burned-in captions, sharing preview/export rendering. With burn disabled, retain cues for sidecar output.
- Caption state in Undo/Redo, non-destructive ripple edits, AutoCut, trim and primary project JSON. V2 project JSON keeps captions in its legacy-primary payload for backwards compatibility; external media remains separately relinkable.
- Experimental browser *on-device* speech recognition through `SpeechRecognition.processLocally=true`, `available()`, `install()` and `start(audioTrack)` (not microphone default). **No remote recognition fallback.** Users explicitly choose when to install local language packs. Unsupported browsers retain manual cues and SRT/VTT. Speech processing reads the primary source in real time; timings are rough phrase estimates, not word-aligned.

## Required live acceptance before promoting to a release

| Case | Acceptance criteria |
| --- | --- |
| Import a long WebM/MP4, generate thumbnails and waveform, click V1 and associated A1 | No blank canvas, no black frame on selection; retained picture or new decoded frame is displayed. Repeat after scrubbing, tool changes and partial clips. |
| Click adjacent clips around cut boundaries | Program Monitor freezes existing frame if decoder is seeking, then presents correct target frame without flashing black. Playhead sequence time stays correct. |
| AutoCut on 10+ silent sections, then play through all joins | Observe both video and audio; visually inspect individual frames for flashes. Fix any remaining decoder discontinuity or audio click before claiming professional-grade output. |
| Export same AutoCut at Balanced and High performance | Review decoded exported frames and first/last frames around every join, MP4/WebM when supported; no inserted black pixels from canvas clearing. |
| Add timed cues, style and burn | Captions are visible at correct edited sequence positions; style remains consistent in preview and encoded export; disabling burn leaves clean video and valid SRT/VTT. |
| SRT/VTT round-trip | Text, cue order, milliseconds and interval endpoints remain valid. Imported markup is treated as plain text, not rendered as HTML. |
| AutoCut/ripple/trim & Undo/Redo | All cues shift, clip or disappear with their correct edited sequence position. One Undo restores changes. |
| Save/reload v1 and v2 projects | Existing projects still import; captions, style and burned-caption mode survive JSON round-trip. Actual source media must be relinked as before. |
| Local speech recognition | Browser displays explicit unsupported/pack-required states; transcription never silently falls back to network recognition or microphone input. Test with and without installed browser language packs. |
| Accessibility and responsive UI | CC1 cue buttons keyboard accessible, controls remain reachable in fixed viewport, editor works in Chrome, Edge, Firefox. |

## Technical gates

- `.github/workflows/checks.yml` runs all existing tests plus `tests/captions-v072.cjs`, `tests/preview-continuity-v072.cjs` and `tests/caption-speech-v072.cjs`.
- `tests/clip-studio-mock.cjs` additionally exercises actual Clip Studio caption state, AutoCut ripple/Undo, V1 selection continuity and project round-trip.
- CI produces a verified **unreleased, unpacked extension development ZIP** on the feature branch.
- Browser memory use and local ASR language pack download size require user-specific testing. No browser-store signing or physical Wacom certification is implied.

## Release decision

Keep `main` and immutable v0.6.18 alpha.2 artifacts as last-known-good while this PR is reviewed. If manual preview and encoded-output acceptance passes, prepare a new explicitly versioned prerelease from a verified commit with a matching manifest, full source package and checksums. Do not promote experimental recognition as a universally supported captioning feature.
