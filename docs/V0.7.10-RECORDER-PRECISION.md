# Recorder Precision 0.7.10 development preview

Base: Creative Foundation 0.7.9. This is the recording-focused A/B pass, not the later image/video Tool Studio overhaul. No new manifest permissions, AI or native companion changes. Numeric manifest version remains 0.6.18; version_name identifies preview.

## Controls

- Tap top-row 1 or physical NumPad 1 for less than 250 ms: toggle persistent spotlight on key release. Key down enables a momentary overlay immediately. Hold for 250 ms or more: releasing restores the previous persistent value. Multiple simultaneous 1 keys restore without a tap toggle. Repeats are ignored, keyup always releases the owned key, blur and hidden document release the temporary effect, modal opening releases it. Focused inputs/textarea/select/editable content and modal dialogs are excluded. Spotlight quick button mirrors inspector state; recipes contain only persistent settings. No capture or system-wide key hook.
- Ctrl+Backquote: toggle Interaction once per press. The mode persists until toggled, source replacement or stop. Ink pointer events disabled in Interaction. With explicit linked-page scrolling consent, ordinary wheel forwards to that page. Native wheel forwarding separately requires a user click and browser permission; disabled when leaving Interaction. Only one forwarding route at a time. If native disable fails, Interaction stays on rather than falsely indicating ink is safe. Ctrl+drag/wheel camera behavior and Ctrl+Alt+0 remain.
- Shift+Backquote / ~: open capture source selection dialog. Choose another monitor or capture surface using the native browser picker; source selection requires fresh user activation and cannot be scripted. Capture monitor type is hinted, and switching an entire-screen capture to a known non-monitor type is rejected. No physical display enumeration or silent switching. User-selected source may be the same monitor.
- Ctrl+E clears ink only; Ctrl+Z undo. Existing recording annotations preserved on source swap. Camera and cursor tracking link reset; source-specific linked-scroll consent is revoked. Explicitly re-link after source replacement.

## Continuity

Stage candidate stream and a decoded frame in a separate video element, with bounded preparation timeout. Old stream, canvas, encoder and local recovery session remain active until replacement is ready. Cancellation, rejection, invalid source and delayed picker result leave the current session unchanged; stop releases pending candidates and late results. Old-source ended callbacks are identity-guarded. Fixed original output dimensions; use aspect-fit black bars, actual source crop dimensions and normalized cursor mapping. Ink remains in output coordinates. Existing audio destination and microphone remain; shared-audio tracks for replacement are connected to the same destination and old shared-audio nodes disconnected. When shared audio was requested, reserve a stable destination track even if the initial source provides none. Missing replacement audio means silence for that source, microphone remains if available. Cannot guarantee system audio availability or uninterrupted capture if browser/OS terminates the previous source. Output may include the native picker and the operator's actions if visible in the captured screen; no claim of frame-perfect physical monitor cut.

## UI

Compact Cursor Focus panel with primary controls, inline state, optional appearance/motion, tracking/permissions and JSON sections. Monitor toolbar contains Spotlight and Interaction; transport contains Switch source. Carbon theme and semantic overlay stack retained; native modal owns focus and bounds. Source picker is explicit and cancelable.

## Validation

Pure tests cover tap/hold thresholds, repeat, overlapping keys, focus exclusions, geometry. Existing recorder regression tests updated for user-requested shortcut contract. Real Chromium test supplies synthetic authorized streams (native OS picker is not automated) and actual canvas/audio/MediaRecorder, verifies pixel mapping and a single decoded output with both source colors, original dimensions and audio track, same session, cancellation, old track release and late-result cleanup. Browser UI screenshots are captured from running code. Physical Windows Edge/Chrome multiple monitors, real system audio permissions and Firefox, Wacom, and off-focus system shortcuts remain manual/future qualification. No added native global monitoring.
