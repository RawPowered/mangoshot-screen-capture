# v0.7.25 Precision Drawing and Brush Studio development preview
Base 31515a1c5117b80398883b65d6af4c65dff26bbc. Retain last fully qualified v0.7.23 preview until the subsequent full suites pass.

## Features and contracts
- Brush Studio in Image Studio, advanced pen and highlighter opt-in; legacy remains default. Six real renderer preset tiles: Precision round, Soft airbrush, Inking nib, Calligraphy, Flat marker and Soft flat brush. Round/chisel/square tips, hardness, per-dab flow, fixed-distance spacing, tip aspect, angle, minimum width, separate pressure width and pressure flow switches.
- Monotone five-knot piecewise-linear pressure curve (endpoints fixed; three draggable inner knots and numeric controls). Not a spline or hardware driver calibration. Existing browser Pointer Events pressure and coalesced sampling; no Wacom proprietary SDK. Live renderer preview and separate local pen test pad. Mouse/touch use full pressure.
- Local brush preferences and up to 12 named custom presets; no server or telemetry. Apply to new strokes or a single visible unlocked selected pen/highlighter layer. Existing strokes snapshot their own profiles, raw pressure samples retained. Selected stroke edit revision checked and undoable once. Escape leaves document unchanged. Overall opacity applied once to isolated stroke; flow accumulates per dab. Highlighter retains its .27 opacity factor. Legacy physical eraser, stroke eraser, redaction and old strokes retain their painter. No new permission.
- Deterministic arc-distance sampling, maximum 8192 dabs per render, adapt spacing on very long strokes, bounded clipped scratch region, local 128px tip stamps with 32-entry cache. Advanced brush limited to 16MP document; larger captures use legacy brush. No performance claims until measured. Tip softness for square uses radial gradient within a square stamp; no procedural texture, scatter, tilt mapping or tilt-aware GPU acceleration.
- Native project v3 stores per-stroke brush profiles plus v2 composition. v1/v2 remain readable and are still saved when no advanced profile is used. Reject incompatible or invalid profile, malformed curve, non-pen/non-highlighter use. The older project reader cannot open v3. Original editable sources remain private.
- Preserve all preceding regression, actual extension Chromium tests for pen pressure via CDP, custom preset, non-mutating preview, selected edit, exact undo and save/reopen pixels, compact modal and package contents. Physical Wacom, Firefox/Edge, high-DPI and large drawing stress remain manual qualification. Advanced gradients, multi-shadow/glow, editable Rust raster effects, clipping masks and group tree UI are separate work.
