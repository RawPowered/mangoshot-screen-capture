# MangoShot v0.6.2 — Focused Clip Studio UIX (Development Alpha 3)

Built from v0.6.1 Creative Tools Alpha 2; prior preview releases remain available. No browser-store certification.

## Workspace
- **Properties inspector:** Clip / Callouts / Camera / Voiceover / AutoCut tabs. Camera and Voiceover now use action buttons rather than tall collapsed strips above the timeline.
- **Single V1/A1 timeline lane:** frame thumbnails and analyzed audio peaks are drawn inside the actual segmented V1 clip surface, not as two additional timeline rows. Razor, segment selection and trim handles remain on the real video clip controls. Thumbnails and waveform stay source-aware through ripple edits, undo and AutoCut.
- **Compact Media Bin:** assets dock across the bottom beneath the timeline; callout layers move to Properties and no longer share the import panel.
- **File → Projects…:** dedicated local project modal with Open/Save v2, source restoration and legacy v1 compatibility. Project JSON never embeds original video bytes.
- **Edit → Preferences → Keyboard Shortcuts:** keyboard mapping is moved to its own dialog; shortcut behavior is unchanged.
- Program Monitor and renderer remain the established v0.6.1 implementations; no silently dropped sources or hidden audio changes.

## Installation and rollback
The incremental overlay requires the exact v0.6.1 Creative Tools Alpha 2 unpacked extension. Back up and export recordings, then extract the root overlay ZIP over the same extension folder containing `manifest.json`, and reload the extension in your browser. For older installations use the complete v0.6.2 extension ZIP. Do not uninstall the old extension or delete browser storage.

## Release gates
Automated regression suites including recorder, screenshot, Razor/Ripple Delete, AutoCut, zoom and narration; additional v0.6.2 workspace structure checks; archive content/hash validation. Browser-native QA on Windows, Wacom, Chrome, Edge and Firefox remains required before stable certification.
