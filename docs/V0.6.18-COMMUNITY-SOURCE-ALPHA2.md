# MangoShot v0.6.18 — Community Source Release (Alpha 2)

**Release type:** documentation, source licensing and distribution refresh.  
**Runtime version:** 0.6.18 (same editor code as v0.6.18-layers-alpha.1).  
**Status:** publicly downloadable development alpha; browser-store signing and cross-browser/Wacom acceptance remain pending.

## What's new in this release

- Replaced the outdated v0.5.7-era README with a detailed feature inventory for Capture, Image Studio, Record Studio, Clip Studio, keyboard shortcuts, creative resources, privacy, installation and troubleshooting.
- Published **MangoShot Community Source-Available License 1.0**, permitting free use, personal/internal modifications and compliant free redistribution while prohibiting software resale and paid distribution without written permission.
- Explicitly reserved RawPowered's rights to develop, license and distribute **future** MangoShot versions commercially or as closed-source software. Earlier compliant recipients keep the license that applies to their copies; future relicensing of external contributions requires the necessary rights.
- Added a contribution policy explaining that outside code contributions may require a separately agreed CLA.
- Included the LICENSE and README inside the packaged browser extension, with a complete source/tools archive and checksums.
- Refreshed release and update guidance to distinguish a documentation-only alpha refresh from a runtime feature change.

**License designation:** *Free to use, source-available, resale prohibited*. This is **not** an OSI-approved open-source license, because free redistribution including resale is required by the Open Source Definition.

## All current MangoShot capabilities (runtime from alpha.1)

### Capture
- Visible-area screenshot, scrolling full-page screenshot and draggable selected-area capture
- Quick Copy to the clipboard and reopening clipboard images for annotation
- Full native-size screenshot composition, PNG/PDF export and annotated-image clipboard output

### Image Studio
- Non-destructive annotation drawing, live text editing, text effects and Wacom-compatible pointer input
- Eleven vector shapes with editable fill, outline, geometry and transforms
- Editable image layers, masks and basic local cutout tooling
- Layer copy/cut/paste, draggable z-order, show/hide/lock, Alt+drag cloning, arrow-key nudge and Undo/Redo
- Live layer opacity, Shadow/Glow/Floating/Crisp presets, appearance controls and style clipboard
- Pressure-responsive Brush Erase, complete Whole Stroke Erase and a local pen-pressure/eraser diagnostic
- Configurable shortcuts, command palette, branded application menus and context actions

### Record Studio
- Browser-selected screen, window or tab recording with supported microphone/source audio
- Local recording controls and recovery workflow, zoom/crop and on-screen annotation

### Clip Studio
- Select/Razor/Range timeline tools, split, trim, ripple delete, snap, thumbnails and waveforms
- AutoCut suggestions for silence/low-motion passages; source media preserved until user applies edits
- Editable text, title, subtitle, lower-third and callout graphic layers; premium-styled visual presets
- Entry/exit motion, type-in/spin-letters, counters, timers and single-source transition treatments
- Browser-codec-dependent video export, local projects and resource directory links

## Important alpha limitations
- The Media Library can stage extra assets without guaranteeing full multi-source composition.
- Transitions are single-source treatments, not full two-source cross dissolves.
- Quick Cutout is not an AI remove.bg/Adobe-grade background removal system.
- Brush erasing annotations and overlay redaction do not irreversibly destroy screenshot pixels.
- Native MP4, system audio, Wacom pressure/eraser-tip events and real-time export performance depend on browser, operating system and hardware.
- Firefox temporary extensions need reloading after browser restart. The extension is not signed/published to browser stores.

## Installation

Download the **full Extension ZIP** from this release, extract it over your existing unpacked MangoShot folder containing `manifest.json`, and reload from `chrome://extensions` or `edge://extensions`. Back up recordings, unfinished projects and the original folder first. For Firefox, use `about:debugging` to reload a temporary extension. Avoid uninstalling or wiping browser extension storage.

Users already running **v0.6.18 alpha.1** do not need a runtime update; alpha.2 adds policy and documentation to the packaged distribution. Users on older versions should use the full extension ZIP rather than guessing which historical overlay applies.

**Developer source:** the Source ZIP for this release includes the full public repository tree with its LICENSE, README, CONTRIBUTING policy, tests and packaging tools.

## Release verification

The release pipeline runs all repository tests, checks browser-extension JavaScript syntax, creates the complete extension and source ZIP, verifies ZIP integrity and publishes SHA-256 checksums.

Passing CI does not constitute physical Wacom or Chrome/Edge/Firefox browser certification. This remains a **prerelease** until real-browser acceptance is performed.
