# MangoShot v0.6.16 — Wacom Pressure Diagnostics & Dual Erasers (Alpha 1)

## Browser and hardware contract
MangoShot uses browser-native Pointer Events, not proprietary Wacom SDK hooks. The HTML Pointer Events specification defines pen eraser button = 5, button state = 32, pressure normalized from 0 to 1, tilt, twist and coalesced movement samples. These values can be absent, constant or remapped depending on the browser, OS, tablet driver and pen configuration. Browser detection does NOT establish hardware compatibility by itself.

Open Image Studio > Tools > **Wacom / Browser Pen Test** and:
1. Draw with the mouse: Device should show **mouse** (not pen). Pressure sensitivity must not be falsely reported.
2. Draw with Wacom pen tip, first lightly then firmly. Device must show **pen**; pressure minimum/maximum should differ. A pen without varied pressure is **not yet confirmed** as pressure-sensitive.
3. Move the pen quickly while down. Observe whether the browser supplied coalesced samples, but zero coalesced samples is valid in a browser that emits individual points.
4. Tilt and rotate the stylus; inspect tilt X/Y and twist values if supported. Zero values may mean unsupported devices.
5. Flip the pen to the physical eraser end, draw on the test pad, check **Eraser tip: Detected**. This requires native button=5 or buttons bit 32. Some Wacom drivers map eraser action to mouse or another event. The manual eraser toolbar remains available.
6. Choose **Copy diagnostic report** to share detected data intentionally. Reports do not include screenshots or filenames, are not uploaded and are not stored.
7. Test Chrome, Edge and Firefox independently, and record operating system, driver, tablet model and browser versions outside MangoShot if useful for triage.

## Two different eraser modes
### Brush Erase (Photoshop-like for screenshot annotations)
- Erases portions of the **composited annotation overlay** with a round brush. Base screenshot is never altered.
- Brush diameter (up to 240 displayed pixels), color-independent erase, variable edge hardness, opacity and optional Wacom pressure.
- Pressure affects brush width/strength when **Use pen pressure** is checked. Mouse falls back to full pressure.
- Each pass is a serializable erase-brush annotation layer and can be undone/redone.
- Canvas preview, Copy screenshot, PNG and PDF use the same painter.
- Existing legacy erase strokes still render for backward compatibility.
- This is an **annotation compositor eraser**, not a native destructive bitmap editor: annotations added after an erase layer can appear above it; use the layer stack/Undo if necessary.

### Whole Stroke Erase
- Click or sweep across an annotation to delete that **entire unlocked annotation object**. Supports pen, highlighter, vector shapes, text and redact annotations. Does not erase or delete imported images, which have a separate image mask tool.
- Skips hidden and locked annotations.
- Dragging across many objects is one Undo step; Ctrl+Z restores them all.
- Removes the layer from the real model, not merely CSS-hiding it.
- The actual screenshot image never changes.

### Wacom physical eraser
- With **Detect tablet eraser tip** on, a recognized pen eraser press *temporarily* uses the most recently selected Brush Erase or Whole Stroke Erase mode without changing the toolbar's active pen tool.
- If the driver does not deliver eraser signals, manually choose the eraser mode. Barrel/right clicks are not interpreted as eraser events.
- Pointer Events coordinates are mapped to native screenshot pixels across Fit and fixed zoom; coalesced pointer samples help preserve fast pen strokes.

## Safety, quality and limitations
- No new browser permissions, cloud APIs, font/model dependencies or telemetry.
- Original screenshot is preserved. Painting over or erasing a redact layer can reveal screenshot content; **visual redact annotations do not constitute certified irreversible redaction**. Do not share sensitive images solely on that basis.
- Pressure range on the test pad indicates the **browser's observed values**, not Wacom hardware identity. There is no remote hardware certification.
- Compatibility testing must be performed with a connected physical tablet in Chrome, Edge and Firefox. Validate Wacom driver, pen nib, end-eraser, pressure extrema, cursor alignment with 100%/Fit, fast/slow lines, large screenshots, Undo, clipboard, PNG and PDF export.

## Install / rollback
**Upgrade ZIP** requires unpacked v0.6.15-vector-tools-alpha.1. Back up extension folder, extract overlay directly over the root holding manifest.json and reload at edge://extensions, chrome://extensions, or Firefox about:debugging.

**Full ZIP** is suitable for fresh installs and older versions.

**Rollback**: restore the saved v0.6.15 folder and reload. Do not uninstall or clear browser extension storage containing local recordings or capture state.

Release remains an **alpha** until hands-on hardware and cross-browser QA pass. Automated tests cover simulated pointer input and deterministic Canvas painting, not physical Wacom performance.
