# v0.7.48 Precision Canvas

Base c338ce6625535c0e76512ce05660bc81ed8d2e4a. Existing image canvas and tool registry preserved. Rulers show source-pixel positions at current zoom/pan; drag from horizontal or vertical ruler to create session-local horizontal/vertical guides (up to 32 per axis), clear together or hide rulers. Existing Snap checkbox is the authoritative toggle, now available at the monitor and used by single and batch layer moves against visible layer bounds, canvas centers/edges, manual guides and crop frame. Alt while moving bypasses snapping; Alt at drag start retains clone behavior. Guides are not saved in projects or rendered into exports. Crop is a non-destructive integer output rectangle stored in native project v13, not destructive resizing or a privacy-redaction tool. Full source, layers and source-space coordinates remain intact; annotated copy, PNG and PDF use the crop, Copy Original explicitly retains full original. Draft handles, ratios, exact values, Enter/Escape, undo/redo and reset. Applying full frame clears crop; existing project versions retained if no crop. Existing source image budget and permissions unchanged. Crop remains an output frame, not a new coordinate system; guide persistence, selection algorithms and retouch tools deferred. No main/stable merge. Representative packaged tests gate release.
