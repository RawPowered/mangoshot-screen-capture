# MangoShot v0.6 — Workstation Shell & Local Asset Registry

**Status: DEVELOPMENT BRANCH, NOT A GITHUB RELEASE.** Based on `v0.5.7-preview.1` to preserve the fixed screenshot and recorder baseline.

## Delivered in 0.6A / 0.6B

- Compact graphite/charcoal Clip Studio workstation chrome, native menu-bar commands, icon/tool rail and accessible tooltips. Existing working controls are still wired, not redrawn as inert controls.
- Independently resizable Project Bin and Properties columns on desktop; responsive stacked layout for smaller displays.
- Media Bin accepts local JPEG, PNG, WebP, AVIF, GIF, MP4, WebM, MOV, OGV and common audio files. Previews images/audio/video locally; shows file metadata; revokes temporary object URLs on removal.
- Project v2 model: deterministic local asset metadata, V1/V2/V3/A1/A2/G2/G3 track descriptors, references to file identities, timeline clip start/end/source times, and explicit `staged` state. No media bytes are embedded in the JSON.
- v1-to-v2 migration preserves exact v1 trim/razor decisions and legacy text/callout data instead of flattening them. V2 project import checks IDs, file metadata and source-relink constraints.
- Secondary media can be **staged** to V2 (image/video) or A2 (audio) for future compositing. Staged assets are **NOT yet rendered, played, or exported**. The UI and saved project mark this limitation plainly.
- Tests cover metadata validation, disallowing remote/script pseudo-media, resource cleanup, v1 conversion, duplicate IDs, track compatibility, reference integrity, and preserving old controls.

## Deferred deliberately to phase C/D/E

- Multi-source video/audio decoding in a shared timeline clock.
- Visual overlays of imported images/video and audio mixing for preview/export.
- Frame-exact rendering of multiple layers and accelerated multi-source export.
- Stable browser-store publication. `v0.5.7-preview.1` remains the current user download.

## How to evaluate

1. Install from the **development branch** in a separate unpacked extension directory (after exporting any unsaved recordings). Do not overwrite your working preview installation.
2. Open Clip Studio, import a primary recording and run a familiar Razor/AutoCut/Ripple Delete test to ensure no regression.
3. Import two images, a secondary video and an audio file into Media Bin. Inspect previews, metadata and duplicate handling. Stage each asset and verify V2/A2 staging rows are labeled **not exported yet**.
4. Save a project v2 JSON. Confirm it contains references and timing only, not raw file bytes or blob URLs. Open it again and relink matching local files.
5. Verify old v1 project save/load still functions. Confirm successful v1-to-v2 migration and that import of a mismatch cannot overwrite the current edit decisions.
6. Test panel resizing, keyboard access, Wacom pen pointer clicks, responsive layout and export controls.

## Release gate for Phase C/D

Before merge into stable, imported video/image overlays must appear correctly in both preview and final render, audio must retain sync, multi-track ripple/undo must respect track locks, no source project or recording may be lost, and Chromium/Firefox hardware tests must pass.
