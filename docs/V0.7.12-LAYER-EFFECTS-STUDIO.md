# Layer & Effects Studio 0.7.12 — development preview

Based on qualified Tool Studio Professional commit 160c6b62fb9f3d438bf681335518d37b256c002d. Adds a common native modal, available from the original layer inspector and creative menu in both editors. No AI, capture, recorder, permission, font, native companion, or numeric manifest version change.

- Search names, types and folder paths; filter visibility/lock state; select individual layers, shown results or folder descendants; collapse nested folders (up to four levels). Folder membership is stored with each layer and participates in the existing undo/redo model. Clip project JSON preserves it. Image Studio remains session-local, consistent with its existing image editor.
- Batch move to folder, up one folder, rename with numbering, duplicate, delete, lock/unlock, show/hide, front/back, and G2/G3 track assignment. Organizational folders do not reorder rendering or alter timeline timing. Empty folders are not persistent entities. Clip operations target existing graphic layers (titles/callouts), not source video tracks. Select in editor chooses the image multi-selection or the last selected Clip graphic. Locked layers reject geometry/appearance/deletion; redaction and eraser appearance is protected.
- Effects modal has 11 presets, opacity, shadow/glow color, blur, signed offsets, blend, graphic fade in/out and graphic outline. Draft preview never commits; explicit checked fields apply across selection as one undo step. Mixed selection changes only checked fields. Existing image renderer and layer-style fields retained. Clip layerFx is optional and validated on project load; a reusable transparent per-render-target Canvas2D buffer composites a whole graphic with the effect, including premium materials, after the existing motion/style painter. Browser preview and browser video export share MangoGraphics.render. Legacy cut-only native renderer still rejects visible graphics. Video effect distances scale relative to 1080p; image distances are source pixels. Image blending is within the annotation stack, not against the base screenshot. The image modal draft preview scales the current composition; clip preview is selected graphics at the first selected graphic midpoint over neutral colors, not a simulated source-video frame. Existing old controls remain accessible.
- No claim of arbitrary effect stacks, true isolated folder compositing, empty folder creation, image-project disk persistence, source video grading, new media tracks, or native GPU acceleration. Full-size effect buffer may add overhead on large frame sizes; manual 4K/Firefox/Edge and physical Wacom tests remain outstanding.
- Added pure and real Chromium regression gates: checked batch operations, group hierarchy, pixel difference using the actual video renderer, old project validation and group/effect round-trip, undo and compact viewport. Existing gates remain enabled. Preview branch only; no merge or release promotion.
