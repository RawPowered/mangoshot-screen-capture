# MangoShot v0.6.13 — Text Layer FX & Aspect-Locked Resize Handles (Alpha 1)

## Text effects (editable, non-destructive)
- Every editable text layer supports **Drop Shadow**, **Outline/Stroke**, **Gradient Overlay**, **Color Overlay**, **Outer Glow** and **Background Plate**.
- Seven presets: Clean, Soft Shadow, Poster, Neon, Gold Foil, Glass and Editorial.
- Each effect exposes visible controls, including color pickers, opacity/strength, softness, offset and padding. Details are collapsed by default to reduce scrolling.
- The v0.6.13 text renderer is part of the same Canvas2D painter used for on-canvas previews, Copy full annotated image, PNG and PDF, so the effects must be composited identically.
- Styles stay editable (effect values are plain layer properties), and updates are Undo/Redo snapshots. Image imported layers are unaffected by text-effect presets.

## On-canvas resize (image and text)
- Selecting an editable text or image layer shows four interactive corner handles.
- **Default**: drag any corner to resize proportionally, keeping the opposite corner anchored.
- **Hold Shift** during a corner drag to release the ratio constraint and independently change layer width and height (including stretched/distorted text).
- For users who cannot hold Shift, uncheck **Lock proportions** in Layers to keep free resize enabled.
- Advanced numeric width and height edits respect the ratio lock; numerical-free resize works when ratio lock is explicitly unchecked.
- Native pixel coordinates remain consistent across Fit, 50%, 100%, 150% and 200% canvas zooms. A resize creates one Undo step; Ctrl+Z restores it.
- The text Type inspector reports effective visual font size after scaling, avoiding confusion between its original font setting and the current appearance.
- Resize handles are HTML controls above the Canvas, **not** painted into screenshots or exports.

## Compatibility
- Retains v0.6.12 Layers / Type / Tools / Mask workspace, imported image masks, Quick Cutout, existing click-to-place text and copy/export workflows.
- Retains the v0.6.10 full-page capture/recording pipeline unchanged; no new extension permissions, no cloud services or new model dependencies.
- Original screenshot is preserved. Source image assets remain unchanged by transforms.

## Installation and rollback
**Upgrade overlay**: only for the *unpacked* v0.6.12-layer-studio-alpha.1 extension. Back up the whole extension folder, extract over the same directory containing manifest.json, overwrite matching files and reload under edge://extensions or chrome://extensions. For Firefox temporary installs, reload in about:debugging.

**Full extension**: use for clean installs or older builds.

**Rollback**: restore the backed-up v0.6.12 extension and reload. Do not uninstall or clear browser-local storage that could hold captures/recordings.

Image layer source data remains in-memory until final PNG/PDF export. Editable layered project save/restore is a separate future milestone.

## Validation
- All existing capture, image editor, layer, masking, recorder and Clip Studio regression tests.
- New Canvas2D tests for 7 presets, gradient glyph fills, shadows/outline/glow, shared text geometry, aspect-ratio preservation, free Shift stretch, opposite-corner anchoring and text/image transform immutability.
- Strict overlay changed-file checks, ZIP integrity, SHA-256 digests and extension manifest verification.
- **Manual gate not yet certified:** real browser mouse/Wacom handles at several zoom levels, type readability, large full-page captures, clipboard paste and PNG/PDF visual parity. Keep this as a development alpha until those checks pass.
