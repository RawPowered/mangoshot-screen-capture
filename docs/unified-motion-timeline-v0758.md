## Motion and timing
- Non-destructive graphic transform retiming preserves X/Y offset, rotation, scale and animated opacity on retained sequence time across trim, ripple delete, AutoCut and repeated trims. Sliced eased intervals and discontinuous cut poses remain editable and serialized.
- Moving a whole graphic preserves its internal normalized key timing. Changing In/Out preserves absolute retained key timing; extending edges holds the original endpoint pose. Inserting a transform key without changing values preserves the existing curve.
- Camera events are sliced by retained sequence time. Held zoom poses and cropped motion curves survive cuts, including repeated edits. Cursor paths and effect regions remain anchored to original source time, never rewritten as output time.
- Primary cuts prevalidate the next camera and transform state before changing the timeline/history. Sequence scripts use the same retained-time camera mapping. Overlapping or over-budget camera events and over-budget graphic keys are rejected rather than approximated.
- Direct CAM lane buttons display transition duration, click to open the selected event in Zoom Studio, drag to move, Arrow Left/Right nudge by 1/30 second, Shift+Arrow by one second, Alt-drag bypasses snapping. A cut pose has zero duration and is labeled separately. Old HUD still provides quick framing/add controls; duplicate selected-event editing is routed to Zoom Studio.
- Cursor FX lanes support moving whole regions within one retained source section. Cross-cut and repeated-source regions remain source-time inspector edits. They cannot be dragged blindly across a cut.
- Motion Studio adds precise sequence-second keyframe timing. Graphic numeric In/Out edits and timeline gestures share a validated commit route. Static and animated canvas motion uses a preview-only draft, with one undo step on successful release. Pointer cancel, Escape, blur, or a stale project do not commit the draft.
- Preview and export continue using the same existing committed renderer. Uncommitted UI drafts are not included in export.

## Limits and checks
The exact-retained-time guarantee applies to the five graphic transform keyframe properties and camera curves, not to entry/exit text presets, fades, separate multitrack media, independent Sequence Studio, or unrecorded pointer movement. Graphic transforms retain the existing 32-key limit and camera moves the existing 240-event limit. A cut that would exceed limits is rejected. Camera/cursor timing is on the current 30-fps editor nudge grid, not a new variable-frame-rate engine. Earlier projects with overlapping camera moves must be corrected before retiming. Real Chrome/Edge, Windows hardware, encoded pixel/audio parity, complete control inventory and next UIX pass remain unqualified.
