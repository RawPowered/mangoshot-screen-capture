# MangoShot v0.6.1 — Creative Tools Alpha 2

This development release builds on the v0.6.0 workspace alpha. The known public preview v0.5.7 remains unchanged.

- File → Export / Render opens a separate modal. Properties stays in the inspector with graphics, selection and edit actions.
- Six new text/callout presets: neon lime, glass, numbered step, orange warning, minimal, outline. Wrapped long text auto-fits inside its bounding box; monitor canvas/video use a shared aspect ratio to avoid skew.
- CAM track: Add Zoom and Return to Fit at playhead; configurable ease, zoom level and focus X/Y. Browser preview and canvas export use the same animation model; keyframes are undoable and stored in v2 project JSON.
- A2 Voiceover: explicitly allow microphone access, narrate over timeline playback, Stop, Download audio separately, preview in timeline, and mix narration into browser edited exports. The voice file is session-local, not embedded in v2 JSON. If Web Audio mixing fails, export stops rather than dropping the voice.
- Current MediaRecorder export remains real-time, with approximate cut boundary sync.
- Imported secondary video/images/audio from prior alpha remain staged-only and are not composited.

Test gates: File menu modal; graphic presets and text wrapping at multiple aspect ratios; zoom across cuts/exports; voiceover audio export with microphone permission; save/reopen zoom decisions; prior screenshot/recorder/Razor/AutoCut regression suite.
