# MangoShot v0.6.14 — Quick Copy, Drag Selection & Live Typography (Alpha 1)

## Fast capture routes
The toolbar now presents **Copy** and **Edit** for each of three screenshot types:
- **Visible screen** — current tab pixels directly from the browser's captureVisibleTab.
- **Full webpage** — the existing multi-frame scrolling capture coordinator (unchanged) with separate Quick Copy or Image Studio destinations.
- **Drag selection** — injected isolated overlay; drag a rectangle, then MangoShot removes the overlay *before* capturing the current viewport. Area coordinates are converted at physical pixel scale and cropped to that rectangle. Escape cancels without saving.

**Copy** opens a compact branded **Quick Capture** result page. It attempts to write the original-resolution PNG to the operating-system clipboard immediately, using the new explicit extension permission **clipboardWrite**. If the browser rejects auto-copy or does not support PNG clipboard writes, there is a prominent **Copy screenshot** button and **Save PNG** fallback. A successful auto-copy is confirmed by the page's status indicator; the copy must never be reported successful merely because the page opened.

The result page also offers **Edit this capture** (preserves local capture handoff) and **Edit clipboard image**. Captures are local; no cloud API or third-party upload.

## Edit latest clipboard image
- Toolbar **Edit clipboard image** opens a fresh Image Studio import session.
- The editor does **not** read the clipboard on page load. User explicitly chooses **Paste image from clipboard**, presses **Ctrl+V** on the focused paste area, or chooses **Open image file**.
- Accepts only PNG, JPEG or WebP image MIME types and bounded image dimensions. Text and HTML are not imported as screenshots.
- No blanket **clipboardRead** permission. Chromium may prompt for read access; Firefox may require a paste confirmation. Ctrl+V is the compatible fallback.
- Pasting text in an existing inline text editor continues to use normal text paste behavior and does not replace the screenshot.
- The editor opens with the selected screenshot at native resolution and allows the existing layer stack, masks, overlays, text, PNG/PDF and clipboard export.

## Live typography polish
- Inline text now paints on the *actual* Canvas as every character is typed, **before** placing or committing the text.
- When editing an existing text layer, the draft replaces that layer at the same stacking position, preserving the relative position of shapes and images. **Escape** cancels and restores the previously committed pixels.
- The floating text composer is placed adjacent to the text rather than directly over it when space allows.
- The Type inspector's content textarea also previews each keystroke live. A continuous typing session is a **single Undo step**; blank text on blur reverts to the previous content instead of accidentally deleting the layer.
- Font-size drags and individual text effect sliders paint while adjusting, grouped into undoable gestures.
- Existing text-effect presets, proportional resize (Shift-to-stretch), image import, layer masks and screenshot/recorder services remain available.

## Technical and security constraints
- One **clipboardWrite** extension permission added for automatic PNG writing after the asynchronous full-page capture; no clipboard reading in the background.
- No host-wide permission, iframe, network API, AI inference or telemetry added. User data stays local.
- Image compositing is shared by Quick Copy and selected-area Image Studio import. Existing full capture coordinator continues to obtain browser pixels on the active source tab.
- Quick Capture result keeps local handoff until edited; user should not uninstall/clear storage during an unfinished capture.
- Auto-copy and clipboard read are **best-effort browser APIs**, with explicit UI fallbacks rather than silent failure.

## Installation
**Overlay:** requires unpacked v0.6.13-typefx-alpha.1. Back up the root containing manifest.json and important local projects, extract over that root, and reload via chrome://extensions / edge://extensions or Firefox about:debugging. Because clipboardWrite was added, the browser might request permission/extension reapproval.

**Full ZIP:** use for a fresh or older-version installation.
**Rollback:** restore the backed-up v0.6.13 directory and reload, without uninstalling or deleting browser-local data.

## Qualification gates
Automated: all existing capture, recorder, video, image and text regressions; new region capture protocol tests (intent routing, cancellation, source authorization and capture crop), full-page/visible compositor tests and clipboard-image write/read, live text keystroke and Undo tests, syntax checks, package/overlay SHA256 and CRC checks.

Manual acceptance still required: Chrome/Edge/Firefox full-page auto-copy after asynchronous capture, selected area (scroll/zoom/retina), pasting into Paint/Office, direct clipboard import browser prompts, IME and Wacom text editing, high-resolution screenshots, and export-vs-preview pixel parity. **Development prerelease only until browser acceptance.**
