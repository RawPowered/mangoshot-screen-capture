# v0.7.30 Spatial 3D Arrow Studio
Corrects the product direction of v0.7.29: prior extruded planar callouts are retained as legacy, not presented as true spatial routing. Qualified baseline 75811f9364ef834cd432b1575b0d398048d602ad, run 45869589995, artifact 15142905746 (all applicable automated jobs passed).

## Actual spatial geometry
- 2–12 editable XYZ points, bounded world coordinates, true Catmull-Rom centerline or piecewise-linear route, circular swept tube mesh with transported frames, conical head, vertex normals and actual Z depth. No 2D silhouette extrusion masquerading as spatial geometry.
- Local WebGL2 triangles and depth buffer, perspective projection with near/far clipping, orthographic inspection, directional diffuse/specular lighting. No external libraries, network requests, new permissions or GPU WebGPU requirement. Shared renderer across Image and Sequence composition. Transparent surfaces, capped at 9 MP / 4096 pixels each; bounded 18 MP / 6 surface cache. Very large output layers may upscale the bounded raster. Explicit WebGL2 requirement; no fake 2D fallback. If GPU unavailable, legacy callouts and ordinary editing remain available; spatial creation/open is blocked. Context loss may interrupt redraw; exported composition checks renderer availability.
- Camera orbit/dolly, front/top/right inspections and independent output camera; drag an XYZ gizmo endpoint or a point on the view plane. Numeric coordinates, insert/remove nodes, whole-path translation mode and axis rotation in 15-degree increments. Radius, head radius/length, color, matte/metal/gloss, light and smooth/polyline toggle. Output camera includes azimuth, elevation, distance, FOV, perspective/orthographic. Inspection views not committed until Use view as output. The output-view reference is the current image/video composition, cropped to unrotated layer rectangle and may include the previous version of the shape; it is not a game-world camera solve. Reference and gizmos are never exported.
- Native image v8 / sequence v5 for actual spatial arrows, legacy v1–v7 image and v3–v4 sequence retained. New shapes default to whole composition rectangle for routing, ordinary 2D layer placement/rotation and timeline clips retained. Image spatial-arrow selection uses rendered alpha hit-testing rather than a whole-frame hit box. Sequence G2/G3 remain separate graphics tracks. Real depth testing within each arrow, not between separate composited layers; no automatic depth extraction, camera tracking, occlusion by game objects, 3D scene import, dynamic path animation or live recorder support yet. No automatic migration from planar arrows to arbitrary XYZ paths. Existing speed ramps preserved.
