# MangoShot 0.7.9 Creative Foundation

Base: qualified Carbon Studio. No AI changes, additional browser permissions, native companion change or release promotion. Manifest numeric version stays 0.6.18; version_name identifies preview.

## Local typography
Eight upstream, unmodified Google Fonts TTFs: Manrope, Plus Jakarta Sans, Bodoni Moda, Playfair Display, Oswald, Space Grotesk, Syne, Allura. Normal faces, seven variable-weight families and one regular script face. The asset provenance manifest pins source paths and Git blob SHA-1; each original OFL-1.1 license is included, and font files are not subject to the MangoShot application license. No remote font requests. Stable identifiers coexist with old system-font identifiers. Canvas renderers use local @font-face aliases; selected weight is clamped to a supported range. Export checks refuse missing creative fonts instead of silently exporting fallback typography. Only the new font IDs are added to the existing V1 validation contract. Old project files remain valid; new IDs require the new build.

## Creative library
Layer > Creative Library or the typography/graphic inspector button. Twelve new shared designs: Forged Titanium, Aurelia Gold, Rose Signature, Platinum Edition, Crystal Glass, Nocturne Cinema, Editorial Atelier, Impact Kinetic, Technical Signal, Afterglow Neon, Signature Script, Precision Tutorial. Search, category, custom sample, favorites and recents stored locally, adjustable font weight. Image cards use the real existing text FX painter; video cards use the real graphics/material/motion painters, with hover/focus playback and reduced-motion respect. Material appearances are stylized Canvas2D, not physical metal or glass refraction. Apply to selected unlocked text or insert new text; each is one undoable operation. Image and video use their respective existing effect fields, not an identical raster across studios. Existing effects and video premium presets remain available. Fonts added to normal selectors; video designs also in preset selectors. Custom user font importing, italics, typography tracking/kerning UI, custom saved style authoring, and arbitrary new shader transitions deferred. Favorites are references, not custom presets.

## Icons and packaging
Shared original SVG renderer consolidates both editor tool icon paths and selected command icons while retaining original event handlers and fallback renderers. Existing tool groups and shortcut logic are unchanged. New specialized tools, layer grouping, track rearchitecture and true two-frame transitions remain later roadmap items. All third-party font bytes and OFL licenses checked in the package, no external dependencies. Local browser gate tests actual fonts, image pixels, video project validation, native modal size and undo. Real Windows Edge/Firefox and edited PNG/PDF/video export qualification remain manual gates. No claim of full cross-browser certification.
