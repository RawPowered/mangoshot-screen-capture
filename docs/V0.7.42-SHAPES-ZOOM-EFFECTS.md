# v0.7.42 Shapes, Zoom, Effects

Base 598ab3eb55e966af784a3d1f09b0155d82d5e44b; previous v0.7.41 browser fixture failed because capture ID was invalid, corrected to a valid hyphenated fixture ID without bypassing validation. Qualified v0.7.40 remains installable baseline. Add native Clip Studio shape kind (rectangle, rounded rectangle, ellipse, triangle, diamond, hexagon, star, arrow, line, ring) using shared graphics renderer, track/time and validated project payload. Shape modal provides decoded source preview, direct position/resize, dials + exact values, range sliders for width/height/opacity, stroke/fill and timing. Existing motion and filter stack apply to shapes. Image picker activates existing vector tools; view zoom adds exact percentage/range/Fit. Zoom Studio gains synchronized zoom/start/return sliders and source reference scrub. Existing dials and timing transactions retained. Effects Studio works on selected editable layers, adds editable ordered compositor stack, presets, reorder/remove/enable and dials; appearance and filters have their own tabs. Controls enable relevant effect automatically. Video effect preview uses current decoded frame with camera/grade and graphic animation scrub; not a full temporal render, secondary video/cursor/transitions excluded from this sample. Advanced creative gradients and source grading remain separate specialized tools. Shape bounds and resize are axis-aligned before rotation; shape layer support is Clip Studio, not unified Sequence migration. Project schema v1 recognizes new shape kind; earlier builds reject it rather than silently render it as text. Existing regression and recording gates retained. No stable/main merge.
