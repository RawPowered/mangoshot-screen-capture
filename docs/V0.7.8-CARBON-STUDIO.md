# MangoShot Carbon Studio — 0.7.8 development preview

Base: qualified 0.7.7.2 ChatGPT Tunnel preview. This is a visual/UI-only branch. No new AI capabilities, permissions, native companion changes, editing operations, project migrations, or release tags. Numerical manifest version remains 0.6.18; version_name identifies Carbon Studio.

## Design system

Carbon is the default skin for this preview. The shared theme-carbon-v078.css is loaded last by Image, Clip and Record Studio plus popup, resources and quick-capture. Legacy chrome color declarations are migrated to Carbon semantic variables, retaining the existing layout and selector contracts. The theme is not a runtime recoloring filter, and does not modify canvas drawing code, source media, user-selected annotation colors, actual graphic/text-effect presets, or the brand artwork. Content-facing preset swatches remain expressive. Explicit state colors for warnings, recording and errors retain their meaning.

Foundation: #111315 canvas, #16191c shell, #1c2126 panel, #222830 secondary panel, #2a313a elevated surface, #14181c field, #323943 active surface, #3a424b standard border, #4a545f strong border. Typography: #f2f4f5 primary, #c0c7cd secondary, #9aa4ae muted. Lime #b7ff3c is reserved for selection, active tools, narrow confirmation indicators, focus rings and playhead/handles. Media tracks use subdued steel/slate; recording and destructive states remain warm/red. Subtle neutral elevation, restrained radii, aligned labels, tabular numeric readouts, inset input surfaces and neutral scrollbars. Active tab and toolbar indicators use a thin edge rather than a full neon fill.

## Boundaries

The theme does not change dock geometry, document overflow, pointer events, tool behavior or semantic z-index contracts. Existing native menu/popover and modal positioning remains authoritative. Automation and bridge interfaces are restyled only; they remain installed, not expanded or removed. No companion reinstall is required for the skin.
