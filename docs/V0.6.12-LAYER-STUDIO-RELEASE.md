# MangoShot v0.6.12 — Layer Studio & Image Masking Alpha 1

## User-facing changes

### Compact Photoshop-inspired / Canva-inspired workflow
- Reorganized the Image Studio properties area into focused **Layers / Type / Tools / Mask** tabs.
- Layer list is topmost-first. It includes text, imported images and existing pen/shape/arrow/redaction annotations.
- Per-layer visibility, locking, selection, deletion, duplication, up/down ordering and opacity.
- Imported image and text objects can be selected and moved directly on the screenshot. Image dimensions and position are available under "Advanced size & position".
- Existing annotation Undo/Redo history remains; mask painting, layer order and transforms are undoable.
- MangoShot graphite/lime brand styling is retained with reduced inspector scrolling.

### Imported images
- Use + Image in the top toolbar or Layers panel to import PNG/JPEG/WebP images locally.
- Images are kept in memory as decoded local assets, never uploaded to a cloud provider.
- Import constraints: <=20 MB compressed image, <=8192 pixels per axis and <=24 megapixels.
- Imported layers can be repositioned, duplicated, hidden, reordered, locked, cropped by masking, and flattened into PNG/PDF/clipboard outputs.
- **Important**: only the final flattened image persists via PNG/PDF; imported image layer source data is in-memory for this alpha. Export before closing Image Studio. Native layered project save/restore remains a later milestone.

### Typography
- Six familiar font families including Modern Sans, Editorial Serif, Monospace, Display, Rounded and Classic Serif.
- Existing editable Text, Title, Label, Callout presets and visual Small/Medium/Headline sizing.
- The v0.6.11 inline text placement, selection, move, double-click edit, Undo and Wacom support remain.
- Fonts are system-family fallbacks, so exact appearance depends on fonts installed in the OS.

### Non-destructive masks and Quick Cutout
- Imported image layers have **Mask Erase** and **Mask Restore** brushes, brush width and edge softness.
- Mask paths are separate model data rather than destructive changes to source pixels.
- Mask actions are undoable and combined into the same Canvas compositor used by PNG, PDF and clipboard copy.
- **Remove flat background (beta)**: fast local edge-connected color segmentation for near-uniform backgrounds. This is not AI segmentation and will not handle hair, transparent items, complex lighting or foreground/background color overlap as well as professional models.
- Quick Cutout stores a separate alpha-matte reference on the layer so Undo and Clear Cutout can restore original pixels. No network calls.
- AI-grade removal is deliberately not advertised as shipped. A production-quality neural segmentation engine requires a correctly licensed local model/provider, consent controls, performance budget and quality benchmarks. Example: IMG.LY's browser background-removal package is AGPL-3.0; BRIA RMBG-2.0 weights are CC BY-NC without a commercial agreement. Do not silently bundle incompatible weights/dependencies.

## What is not included yet
- Photoshop PSD import/export, live adjustment layers, vector paths, smart objects, full layer grouping, external smart-object links, edge-aware AI human/product matting.
- Native editable .mangoimg document persistence. Current image layers and masks are in-memory for the editing session.
- Automatic model downloads, cloud APIs, or provider credentials. These need an independent license/security and quality gate.

## Installation
**Overlay**: ONLY for an unpacked v0.6.11-image-studio-alpha.1 installation. Back up current extension folder, screenshot projects and recordings. Extract v0.6.12 files over the same root as manifest.json. Reload in chrome://extensions, edge://extensions or Firefox about:debugging.

**Full extension**: for fresh or older builds. Loading the full ZIP requires unpacking and loading the extension root, not running the ZIP as an installer.

**Rollback**: restore the backed-up v0.6.11 folder and reload. Do NOT uninstall the extension or clear browser extension storage.

## Automated and manual validation
- Full regression suite including v0.6.11 Image Studio copy/paste, text drag and Undo; unchanged full-page capture worker tests.
- New local asset import, visible layer, masking, quick cutout and renderer tests; syntax checks.
- Full ZIP and strict upgrade overlay member, CRC, SHA-256 and manifest checks.
- Hands-on acceptance still needed in Chrome, Edge and Firefox: narrow/wide inspectors; large full-page screenshots; importing, reordering, masking and clipboard/PDF outputs; Wacom pressure/drag; memory and fallback behavior.
- Keep prerelease/draft until browser QA is complete. Do not merge to a stable branch based solely on mocked tests.
