# MangoShot v0.7.4 — Cursor Director (development preview)

Based on qualified v0.7.3. No manifest permission changes, native hooks, executable user scripts, MCP transport, external model inference or release tag.

Clip Studio now has a Cursor category: Effects, Smart Zoom, Presets and Script. The CUR track shows source-anchored regions; add using edited sequence time, update source interval and style, enable/disable, remove. Regions are non-overlapping and capped at 120. Changes use existing undo/redo. Cuts map through source time; restoring footage also restores its effect regions. Preview and export call the same renderer after the camera transform and before graphics. Effects skip unsupported transition transforms, gaps and out-of-frame points. The dot/arrow adds a marker; it does not remove a baked source cursor. Live effects remain baked. Smoothing is deterministic. Click samples are retained only when opted in, up to 6,000; timestamps approximate the next rendered frame and very rapid clicks may coalesce. Old traces work without clicks.

Smart Zoom produces candidate camera ranges from actual recorded click samples or labeled inferred dwell candidates. It does not overwrite active camera ranges or cross a retained clip boundary. Review/select before applying. A stale proposal fails; selected ranges use a single undoable commit. This is deterministic cursor analysis, not narration AI. Custom Director style presets support local save/load/delete and JSON import/export; recorder presets are unchanged. Project v2 saves cursor metadata, regions and camera events; sharing the JSON shares path coordinates. The existing source identity checks (size, duration, format, not a cryptographic fingerprint) must pass before applying creative edits. Opening metadata alone does not apply camera changes. V1 save blocks when effects/camera keyframes would be lost. Standalone path import, native desktop tracking, actual cursor replacement, narration-driven AI, full panel docking and external MCP remain separate work.

Script examples:

~~~json
{"schema":"mangoshot.cursor.director.recipe.v1","action":"effects.add","start":1,"end":5,"style":{"spotlight":true,"ring":true,"pulse":true}}
~~~
~~~json
{"schema":"mangoshot.cursor.director.recipe.v1","action":"smartZoom.propose","settings":{"mode":"auto","scale":2,"transition":0.4,"hold":1.2}}
~~~
~~~json
{"schema":"mangoshot.cursor.director.recipe.v1","action":"smartZoom.apply","proposalId":"<returned-id>","selected":["proposal-1"]}
~~~
Update/remove use region IDs. Add times are edited sequence seconds; update times are source seconds. No shell/eval. APIs are suitable for a future permission-scoped MCP adapter, not an exposed server.

Gates: existing unit regressions, new geometry, recipe, trace and browser UI/pixel checks. The browser smoke uses a deterministic source model, not physical recording. Manual qualification remains for real click timing, export pixel parity, pause/consent, project restore with actual footage, trim/undo/redo, Wacom, short viewports and Chrome/Edge/Firefox.
