# v0.7.35 Callout Designer (development)

Base: 430257da7a319dcbbaa2bcc41fbeb9f6cb03fa44 (v0.7.34 unified scene motion). No stable merge or release promotion.

Sequence Studio adds 14 editable 2D presets (arrows, curved pointers, focus rings, spotlights, ripples, labels, steps, highlights, keyboard keys, notifications, progress and brackets). Existing G2/G3 timed tracks accept 2D or 3D clips; only two simultaneously overlapping shapes are supported. Version 10 adds a validated callout2d recipe, preserves v3–v9 loads, and rejects mixed 2D/3D payloads. Existing opacity, timing, fades, position, size, track controls, lock, undo and project serialization remain authoritative. Motion is clip-local normalized time with independent entrance/hold/exit fractions, deterministic easing and pulses; trimming retimes the preset to the new span. Both live sequence and export use the same Canvas renderer. Spotlight dims the area outside its ellipse; not an irreversible redaction tool.

The staged designer includes 14 rendered preset thumbnails, a scrub/play preview, optional local footage sample excluding the selected object, pointer drag and keyboard nudge, shape/type selection, text/color, synchronized range and numeric controls, opacity, glow, stroke, rotation, dimming and timing. Apply uses the existing validated transaction; Cancel discards staged changes but the newly inserted default clip remains (same as current 3D workflow). No new permissions, remote scripts or assets.

Scope: Sequence Studio only; legacy Clip Studio and recorder remain unchanged. No clickable viewer hotspots, exported HTML player, cursor tracking, automated object tracking, magnifier, full Bézier keyframes, arbitrary layer stacking, or Rust changes in this pass. Existing spatial renderer and scene motion remain unchanged. Native device testing and runtime qualification are pending until CI results are confirmed.
