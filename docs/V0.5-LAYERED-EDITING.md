# MangoShot v0.5 · Layered timeline architecture and release gates

## Scope / project contract

- Existing V1 source video and A1 audio remain immutable. The edit decision list is a sequence-ordered array of source [start,end) intervals.
- `clip-edit-ops.js` maps output time ↔ source time, slices by output time for trim/ripple delete, and splits without merging cut boundaries.
- `clip-graphics.js` owns deterministic G2/G3 canvas overlays, time-bound titles/callouts, preset/default/manual styles, visibility and time reflow after ripple edit. Layer graphics draw behind the editing selection outline but above source video; only actual graphics are exported.
- `clip-graphics-ui.js` binds the left layer bin, two timeline tracks, contextual properties and Wacom/pointer positioning in the Program Monitor. User-supplied text never enters `innerHTML`.
- `clip-project.js` stores edit decisions, layers and markers as a versioned JSON file; the source media is not embedded. Import rejects unexpected metadata and malformed layer values.
- `clip-studio.js` keeps an 80-step snapshot history for cuts and layers; the graphics preview and export compositor call the same MangoGraphics.render function with sequence time.

## Controls

| Action | Shortcut / Control | Notes |
|---|---|---|
| Select | V | Default tool |
| Razor | C | Click V1 to split in sequence time |
| Split playhead | Ctrl+K | No source file changes |
| Ripple delete In → Out | Alt+Backspace | Closes gap, shifts G2/G3 and markers |
| Text / Callout | + Text / + Callout | Custom or preset, time-bound overlay |
| Preview | Space | J/K/L video transport remains available |
| Undo edit/layer | Ctrl+Z | Up to 80 steps in active page |

## Known restrictions

- Additional video or audio imports/tracks, arbitrary transforms, motion keyframes and frame-perfect smart rendering are not in v0.5.
- Browser MediaRecorder re-encodes edited/layered output at approximately playback speed; native MP4 depends on browser codec support.
- Overlay preview uses video element bounds; unusual portrait/letterboxed sources should be checked on hardware before release.
- A saved JSON edit project requires a matching original video file and is not a self-contained media package.

## Release gates

1. Run all Node regression files, verify manifest and ZIP integrity.
2. In headless Chromium, load local WebM, add a title, split/ripple, export and inspect actual output frame, audio codec and container.
3. Test text/callout project round-trip and source mismatch rejection.
4. Test UI at 430/1024/1440 wide; no horizontal overflow or hidden Stop in recorder.
5. Manually certify Firefox, Chrome, Edge; Wacom pointer positioning; title/callout audio/video export and consecutive recording reliability before stable merge.
