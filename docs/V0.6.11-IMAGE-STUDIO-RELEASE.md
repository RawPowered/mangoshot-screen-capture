# MangoShot v0.6.11 — Image Studio: Annotated Clipboard Copy and Inline Text (Alpha 1)

## User-visible changes

### Copy the entire annotated screenshot
- Right-click anywhere within the Image Studio screenshot canvas to open a locally rendered custom menu.
- **Copy full image with annotations** copies the original screenshot plus every committed pen, highlighter, eraser, shape, redaction and text annotation, at the image's original native width and height. It is not limited to the visible zoomed viewport.
- **Copy original image** excludes all annotations. The context menu also exposes Save PNG, Save PDF, Undo, Redo and Delete Selected Annotation where applicable.
- A clearly visible **Copy image** button is also available above the editor.
- The copied image uses the standard `image/png` MIME type in `ClipboardItem`, written to the browser's Clipboard API only following an explicit user interaction. The editor does not request new extension permissions, communicate over the network or use any iframe.
- Copies and exports first finish an active inline text draft so new text is not silently omitted. In-editor selection borders, handles and editing controls never appear in exported/copied images.
- If clipboard access is denied or unsupported, MangoShot provides an actionable status message and the existing Export PNG path remains available. Sensitive screenshots are not sent elsewhere.

### Image Studio typography and tool UX
- Added the **Select / Move** tool to the Image Studio rail.
- Choose **Text**, click directly where the text should appear and type into a highly visible inline text composer. `Enter` places it, `Shift+Enter` creates a new line and `Escape` cancels.
- Placed text is immediately selectable and movable by dragging. Double-click an existing text annotation to re-edit it in place.
- The right inspector now exposes text content, four quick styles (Text, Title, Label and Callout), a usable size slider, font family and fill color. Generic drawing stroke-width controls are hidden during text editing.
- The annotation objects list now allows selection, text re-editing and one-click deletion, with relevant controls accessible to mouse, keyboard and Wacom users.
- Undo/Redo snapshots are now deep copies so repositioning and text changes genuinely revert rather than mutating history.
- Image Studio uses the existing MangoShot graphite/lime branding with a compact responsive properties layout.

## Engineering and safety
- The existing full-page capture background, service-worker handshake, capture storage and recording pipeline remain unchanged.
- The original screenshot remains a separate immutable base canvas; annotations are non-destructive on the ink canvas.
- A new local `image-editor-core-v0611.js` module handles deterministic multiline text layout, hit-testing and image composition.
- The screenshot clipboard path uses `navigator.clipboard.write([new ClipboardItem({'image/png': promiseForPngBlob})])` directly within the user gesture, supporting deferred full-page PNG encoding where allowed by the browser.
- No new browser permissions, no cloud, no tracking or remote calls.

## Install / rollback
**Overlay** applies ONLY to an existing unpacked `v0.6.10-capture-layer-alpha.1` installation.
1. Back up the entire existing extension folder and any important original captures/projects.
2. Extract the overlay into the SAME extension root containing `manifest.json`.
3. Reload in `edge://extensions` or `chrome://extensions`. Firefox temporary extension: `about:debugging`.
4. Capture a webpage, annotate it, right-click and choose **Copy full image with annotations**. Paste into an image-aware application.
5. Test creating and moving text, then Undo and copy again.

**Full package** is for new installs or older versions. Rollback by restoring the backed-up v0.6.10 folder and reloading; do not uninstall and clear browser storage.

## Release gates
- Automated regressions plus mocked native-resolution ClipboardItem tests, text placement, drag/Undo and right-click menu.
- Root-overlay strict changed-file diff, source file checksums, ZIP member/CRC integrity and full-package validation.
- Manual acceptance still required in Windows Chrome/Edge/Firefox on a real long full-page screenshot, 100%/Fit zoom, Wacom input and pasting into real destination apps.
- This is a development alpha pending browser verification, not a stable release.
