# MangoShot v0.6.0 Workspace Alpha 1 — Overlay Patch

**Developer test-drive only.** The last public tested MangoShot preview remains `v0.5.7-preview.1`.

Download the **MangoShot-v0.6.0-workspace-overlay-from-v0.5.7.zip** asset below. This is a **root-level file overlay**, not a complete fresh installation.

## Installation

1. **Export any recordings or projects you need to preserve.** Do not uninstall the existing extension or clear browser data.
2. Back up your current unpacked MangoShot extension folder.
3. Confirm your existing `manifest.json` is **v0.5.7** and the folder contains `clip-studio.html`, `recorder.html`, `background.js`.
4. Extract the **contents of the overlay ZIP directly over that same folder**, overwriting existing files. Do not create an additional nested `MangoShot` folder.
5. Open `chrome://extensions` or `edge://extensions` and click **Reload** on MangoShot. Firefox: use `about:debugging#/runtime/this-firefox` to reload the temporary `manifest.json`.
6. Open **Clip Studio** and test the new workspace and local media bin.

The archive only changes eight extension runtime files and contains `README-OVERLAY.md` plus `PATCH-MANIFEST.json` describing exact file hashes and the required base. **Do not install this overlay on older v0.5.6 builds.**

## What it includes

- Compact professional Clip Studio interface with media bin, editing tool rail, menu, and panel resizing
- Local image/video/audio imports, previews and relinking
- Project v2 schema and migration from v1 project documents
- Existing v0.5.7 screenshot capture/recording source preserved

## Important limitations

Imported secondary media is **staged, not yet composited or exported**; this release is not a multi-source renderer. The overlay is not a signed extension or a stable release.

## Rollback

Restore the files from your original **v0.5.7** extension folder backup into the **same location**, then reload the extension. Avoid deleting browser-local recordings or changing the extension folder path.
