# v0.7.29 Motion & Dimensional Callouts
Development branch based on 4d4c293cc4ecb1e202302a53e3496eb5d5392ec4. Keep the last fully qualified preview until all gates pass.

## Speed ramps
Sequence Studio video/audio clips only. Two to eight rate points along output time, piecewise-linear interpolation, exact trapezoidal/piecewise quadratic integral maps to source timestamp. Rates 0.25x–4x, fixed timeline span, derived source out, explicit source duration validation. Editable preset/graph/numeric points; no optical flow, reverse, freeze or bespoke audio time stretch. Native playbackRate and media-element audio, existing bounded drift checks, same source mapping for stills, playback, waveform and export. Source ranges can be edited numerically; drag-trim for ramped clips blocked to prevent silently reparameterizing. Dissolves and ramps on the same clip blocked. Moving preserves mapping. New sequence schema v4, reads v3. Existing normal projects still use v3.

## Dimensional callouts
Shared procedural polygon extrusion with actual depth, orthographic X/Y/Z rotations, bounded projected face geometry and flat lighting, optional matte/metal/gloss shading. Curved and straight arrows, chevrons, pointers, plaques; curvature, shaft/head dimensions, extrusion, color, lighting direction and orientation editable with real renderer preview. Not a full scene renderer, perspective, texture system or physically based material. Canvas2D draws projected faces. Image Studio stores a dimensional recipe in ordinary editable shape layer with existing position, size, outer rotation, opacity, material/effect stack and undo. Native image v7 includes v1-v6 compatibility. The legacy rectangle controls are hidden when editing this shape; geometry uses the dedicated modal. Sequence Studio has G2/G3 tracks for simultaneous dimensional shapes with titles/video on independent tracks; fixed-duration timed clips with placement, dimensions, opacity, fades and inspector geometry. No shape animation keyframes yet. Clip Studio (legacy recording editor) is unchanged. No external assets or permissions.
