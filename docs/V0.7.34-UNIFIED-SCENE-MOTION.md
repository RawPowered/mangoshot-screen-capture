# v0.7.34 Unified Scene Motion
Qualified baseline 82414c893aaa8027aa125bbce69eb1b3e63139a2; full run 45873440181, install artifact 15144745874. No stable merge.

## Motion model
Sequence Studio unified scene clips now support independently timed object tracks and a single independent shared-camera track. Each track has 2–12 clip-local keys with 1% separation, fixed endpoints, linear/smoothstep/hold easing. Up to eight object tracks and one camera track, 108 total keys. Per-object XYZ geometry, tube/head dimensions, color and light interpolate; material, smoothing and projection are held until the next key. Per-object path reveal is evaluated by the actual mesh generator. Camera azimuth/roll use shortest-angle interpolation, with target XYZ, elevation, distance and FOV interpolated separately. Stable object IDs and fixed primitive/point topology; analytic adjacent-edge collision guard. Pose morphs are not quaternion rigid-body animation. The shared WebGL2 renderer draws all animated meshes into the same depth buffer, with independent reveal values. Transparent transient surfaces released after drawing, no per-frame cache accumulation.

## Workflow
Create the static scene using existing explorer, then Animate scene. Select independent object or camera track in the key strip or selector; enable, choose grow/reveal preset, scrub, add/remove interior keys, choose interpolation, manipulate XYZ geometry using existing gizmos in shared scene context, or edit shared camera numerically and orbit/pan/dolly in actual preview. Object-edit viewport camera is inspection only and cannot overwrite the output camera; camera track is separate. Preview all tracks together; sampling a local footage reference is explicit. Edit selected pose while previewing another time. Scene membership is fixed until all animation tracks removed; remove track keeps canonical first pose. All edits are staged until inspector Apply. Existing static v8 scenes and single-object v3–v7 motion remain unchanged. Native sequence v9 for scene motion. Image Studio keeps static scenes; no image schema changes. No new permissions or dependencies.

## Validation
Pure model tests cover independent tracks, key insertion, angle interpolation, source topology, duplicate/missing references, lock on track creation, collision, first-pose agreement, schema and move preservation. Actual WebGL2 test switches which sphere is nearer as two independently animated objects exchange depth. Browser test drives scene editor, independent keys and camera controls, reopens inspector, encodes video and checks reveal and color pixels, saves native project. All earlier gates retained. Functional SwiftShader tests are not hardware performance certification.

## Scope boundaries
Shared-scene foreground masks remain static; individual legacy spatial layers retain keyed masks. No automatic footage tracking/depth extraction, new Bezier tangent handles, quaternion transform animation, transparent mesh sorting, presets library or GLTF import in this pass. Motion editing is sequence-only, not legacy Clip Studio or recorder. Preview uses a sampled still of footage; timeline playback/export use actual sources. Real-time video encoding can drop frames. Manual Windows/Firefox/hardware performance remains outstanding.
