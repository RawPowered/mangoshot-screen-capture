# v0.7.38 Zoom Studio recovery

User reported unusable Zoom Studio and absent dials. Base ffa9628e0da7d6d1f29e2ee65ed7f8fa7192307a; previous v0.7.37 tests exercised Sequence Studio only for new callout/Smart Focus features. Clip Studio is a separate legacy video editor, including recording handoff. This patch explicitly integrates a native Zoom Studio dialog in Clip Studio top navigation and Camera property tab; no need to switch to an independent sequence or transfer a recording. Open without media gives a visible explanation. Preview shows decoded source with drag/resize framing and matching draft crop, not a dummy graphic. Four keyboard/drag rotary dials, exact fields, zoom presets, automatically fitted range and return, staged camera key list, edit/remove, cancellation and one atomic undoable commit with stale-state protection. Existing camera renderer and export retain authority. Legacy range defaults now remain strictly inside the clip; adding an out-of-range key no longer writes an invalid project. Clip graphic inspector gains synchronized rotary controls for opacity, width, shadow and text size; original properties commit once per drag. Image Studio's existing precision modal is labeled Precision dials and shows build name. Popup labels distinguish the two video workflows; manifest display version is current while numeric version stays 0.6.18 for existing package compatibility. Advanced Smart Focus/keyframes remain independent Sequence Studio only; no project transfer or stable release. User's installed copy has not been directly inspected. Browser and artifact gates required before installing.
