# MangoShot v0.6.10 — Capture Reliability, Premium Quick Add & Layer Delete (Alpha 1)

## Changes

### Full-page screenshot startup
- The toolbar popup now sends a capture session tied to the active tab ID **and** window ID.
- The background acknowledges INIT and content SETUP / SOURCE_START synchronously rather than depending on a long-lived asynchronous popup port during startup.
- A transient closed-port initialization retries once using the same capture ID (idempotent in the coordinator); a persistent worker failure now explains how to reload the extension instead of presenting only an opaque browser error.
- Source frames remain captured one-by-one in the active webpage, stored locally in IndexedDB, and opened in Image Studio. No new permissions or remote service.
- A background worker protocol test exercises popup start, session retry, frame capture, local save, and editor handoff.
- **No claim of live-browser resolution yet:** verify on a normal long HTTP(S) page in Edge/Chrome/Firefox. Browser-restricted pages and images beyond existing memory/dimension limits remain unsupported.

### Faster Premium Studio insertion
- Direct green **+** on every premium card inserts that composition with one action.
- Double-clicking a selected card also inserts.
- A small sticky selected-preset toolbar keeps **Add to timeline** and Preview in view without scrolling to the bottom.
- Default collection opens at Titles (six cards) rather than 24 all-at-once; category/search remain available.
- Enlarged preview typography is readable in narrow property panels.
- Composition rendering and project persistence still use the existing v0.6.9 Canvas compositor; new controls do not generate watermark output.

### Layer deletion
- One-click Delete icon on **each** graphic layer.
- Delete selected layer even while Layers tray is collapsed via the small header control.
- Delete / Backspace key on focused G2/G3 timeline chips and layer rows.
- Global Delete handles the current selection, deleting a graphic layer or selected clip/range appropriately. Alt+Backspace remains a video Ripple Delete command.
- Locked graphic layers cannot be deleted; unlock first.
- Every successful graphic deletion is a single undoable edit. Ctrl+Z restores it.
- Selecting or inserting a graphic clears stale V1 clip selection, protecting the source video from accidental ripple deletion.

## Installation
**Overlay:** only for an unpacked **v0.6.9-premium-brand-alpha.1** installation. Back up the extension folder and important project JSON. Extract the overlay directly over the same folder containing manifest.json, overwrite matching files, then reload at chrome://extensions or edge://extensions. Firefox temporary extensions: about:debugging.

**Complete ZIP:** for clean installation or any older extension baseline.

**Rollback:** restore the prior v0.6.9 folder and reload. Do not uninstall/clear local extension storage, because recordings or screenshot data may live there.

## Verification
- GitHub automated regression and capture protocol tests.
- Package integrity checks include ZIP member lists, CRC, SHA-256, manifest version and strict overlay changed-file equality.
- Browser manual gate: Edge/Chrome/Firefox full-page screenshot of a long dynamic page; sticky headers and scroll restoration; full capture memory limits; PNG/PDF export; source page remains intact; Wacom and keyboard delete interactions; premium insert and Undo.
