# Transform & Material Studio 0.7.15 — development preview

Based on Professional Compositor 477d2d117ebbf4d979758d8188e725a9bd66e4a6, which passed unit tests but had a Layer Studio Escape regression in Chromium. Retain v0.7.13 as the fully qualified baseline until this complete regression passes.

Image rotation: persisted per-object signed degrees (normalized to [-180,180)), center pivot, visible rotation handle, Shift 15° snapping, numeric angle, ±90° and reset, batch rotation through Layer Studio. Applies to editable text, imported images, vector shapes and pen/highlighter marks. Locked, hidden and redaction/eraser objects are excluded from rotation. Rotation is applied in the actual annotation renderer, including preview and PNG/PDF export. Inverse coordinates for hit testing, text editing, imported-image masks, whole-stroke erasing; rotated AABB for batch alignment; rotated corner resizing preserves opposite anchor. One undo step per completed gesture; Escape cancels draft rotation. Base image is untouched.

Material Studio: new tab in the shared Professional Compositor, ten visual presets, gradient and layered metallic sheen, stylized glass, raised/recessed alpha-edge bevel/emboss, intensity, two colors, edge depth, direction, before/apply workflow. Materials operate on the rendered alpha silhouette, then existing ordered effects and outer appearance. No true light transport, frosted-background refraction, texture import or GPU shader. Material raster capped at 16 million pixels per full-size buffer; actual memory/4K performance needs hardware testing. Clip graphic material is validated and stored in v1/v2 project files. Material filters use the same graphics renderer for preview and browser export.

Central Escape routing covers the three advanced dialogs, even when re-rendered controls lose focus. Existing keyboard bindings and unrelated native dialogs unchanged. Previous browser qualification is required as part of this branch. Independent media tracks, per-clip grading, timeline keyframe markers and multi-source transitions remain outside this implementation. Staged assets remain staged, not composited. No release promotion, permissions changes or main merge.

The follow-up hardening exposes numeric rotation without expanding Advanced size & position, skips geometry calculations for unchanged objects, and adds an asymmetric imported-image mask/PNG export browser proof.
