# MangoShot v0.4 Studio — Engineering Preview & Release Gates

## Version and scope

v0.4.0 is a **test-drive preview**, not a browser-store release. It is built on the last confirmed v0.3.2 screenshot/recording pipeline. The screenshot background, capture source, and scrolling implementation remain unchanged.

### Implemented in this branch

- **Recorder reliability:** Independent per-recording encoder chunks, queue and recovery record. A delayed previous encoder event cannot corrupt the currently active recording. Stop ends source tracks and timer promptly; incomplete encoder fragments remain explicitly marked as incomplete. Recovery selector lists locally persisted sessions, and deletion remains explicit.
- **Camera controls:** Reset Camera permanently visible in the monitor controls, stable Zoom Region tool state, Esc cancels an active region, Wacom Ctrl+vertical drag dolly, Ctrl+Alt held scrolling when browser API/linked-tab permissions allow it.
- **Professional workspaces:** Shared graphite visual system across recorder, screenshot editor and Clip Studio with tool rail, program monitor, properties and export panels; responsive stacking for narrower browsers.
- **Clip Studio:** Time ruler and playhead, scrub-to-time, horizontal timeline zoom, non-destructive split, markers, J/K/L/I/O keyboard support, thumbnail generation on demand, inward clip trim handles, optional local waveform analysis (when Web Audio decodes the source), existing trim/cut/undo and instant untouched export.
- **Image Studio:** Dedicated tools, active-tool highlighting, properties, annotation object list, 80-step vector-backed undo and redo, PNG and PDF export unchanged.

### Deliberately not claimed

- Browser-independent MP4 encoding/transcoding. Native MP4 remains browser-dependent.
- Frame-accurate codec-level cutting; MediaRecorder exports are approximate and may take real time.
- Reliable waveforms from *all* MP4/WebM sources. Browser Web Audio may not decode a multiplexed video container; waveform analysis is optional and can fail gracefully.
- Remote clicks, typing and application-level control for arbitrary windows in screen sharing.
- A signed Windows companion, OS-global hotkeys, store-ready Firefox permanent installation, or browser certification.
- Fully draggable/customizable panels and arbitrary timeline clip reordering. The v0.4 layout provides professional structure without pretending advanced NLE features are already implemented.

## Why the second-recording bug matters

The v0.3.2 recorder used shared global `chunks`, `recordingToken`, `recorder`, `recoverySession` and related state. It could permit a second recording after the first encoder watchdog while the first encoder still had pending events. The old `onstop` could then be ignored, and original file delivery could be lost. In v0.4 each `ondataavailable`/`onstop` closes over an independent session object, not the next recording's globals. The first session can finish late and download without resetting the second recorder UI.

## Mandatory validation on real Windows browsers

1. **Sequential captures:** 20s video, Stop, verify saved file plays; start another, Stop, verify independent file; repeat 10 times each browser with tab and entire-screen sharing.
2. **Delayed encoder:** Pause, Stop, and test tab closing/finalizing timeout; confirm UI discloses incomplete files and local recovery stays available. Check 4-minute+ recordings under storage pressure; verify no background capture remains.
3. **Wacom:** Pen pressure, Ctrl+drag dolly, persistent zoom region, Esc cancel, Reset Camera, Ctrl+Z 80 steps, browser interaction with Ctrl+Alt only in consented linked tab.
4. **Clip Studio:** Frame thumbnail generation, ruler seek, markers, split, trim handles, undo, edited-preview/export parity, correct audio, MP4/WebM format honesty, instant untouched download.
5. **Image Studio:** Long-page screenshot, visible screenshot, color/pen, objects panel, undo/redo after Clear, PNG/PDF page exports; no CSS layout clipping at desktop 1366×768, 1440×900, 1920×1080 and narrow/mobile widths.
6. **Integrity:** Compare file lengths, audio codec, duration and playable final frame for each exported recording. Check actual Downloads folder rather than assuming a click means file saved.
7. **Privacy:** No outgoing requests, no auto-capture, delete local recovery sessions via the UI and inspect storage quota behavior.
