# Tool Studio Professional 0.7.11
Base: qualified Recorder Precision 0.7.10. No permission, AI, encoder, source capture, or font changes.

Image Studio: stable layer IDs, rectangular marquee selection (intersection; excludes hidden layers and eraser operations), Ctrl/Meta click selection and Shift range in the layer list, select shown layers by search/type filter. Multi-selection deliberately clears single-layer inspector ownership, so a single property edit cannot silently change just one selected item. Align selected unlocked visible layers to selection edges or centers; equal-gap distribution requires three or more layers and sufficient space. Drag selected layers together, optional snap to canvas/other visible layer edges and centers with a six screen pixel tolerance, dashed selection outlines and snap guides are DOM only and never exported. Group nudges, duplication, visibility, lock and delete are single history steps; locked layers prevent destructive or geometry batch operations. Existing single-layer tools, Wacom behavior, clipboard and renderer preserved. Multi-selection clipboard and group masks/hierarchy deferred. The new marquee is not pixel selection or destructive cropping.
Tool Studio: common group registry, SVG rendering, search, local favorites, remembered last image group variant, long-press or right-click variants. Clip Studio groups existing six rail commands and routes the library to the original buttons; no phantom tools or new timeline edit semantics. No arbitrary user-authored group configuration or drag-to-reorder toolbar in this pass.
Preview only: numeric manifest version remains 0.6.18, source branch 0.7.11. Unit and actual browser tests, compact native dialog bounds, current regression suite, package font identity checks; physical cross-browser/Wacom tests remain manual gates. Next: persistent nested layer groups, batch appearance, custom groups, additional image/clip tools and two-frame compositor.
