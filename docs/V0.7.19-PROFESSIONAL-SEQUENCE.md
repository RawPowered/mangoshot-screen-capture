# Professional Sequence — v0.7.19 development preview

Baseline f437f53ff3ef12a03935be3a6fa03439d82b66ed. All v0.7.18 unit/browser/packaging gates passed; installable artifact 15086160622. Keep it available for rollback.

The independent editor is a new Sequence workspace linked from Clip Studio and the extension popup. The qualified recording-oriented Clip Studio remains intact. It uses the Carbon theme tokens, shared Canvas2D compositor, graphic styles, local media registry and waveform sampler. A true independent clock and blank canvas replace the requirement for an initial primary recording. No synthetic clock source or cloud requests.

Project v3: independent name, duration 1–3600 s, even canvas dimensions up to 4096 × 2160 pixels (8.85 MP total), nominal 24/25/30/50/60 fps, background color; V1/V2/V3, A1/A2, G1. V1 supports sequential primary sources, gaps and explicit 0.1–5 s adjacent cross-dissolves (no triple overlap). Adding a dissolve shifts later V1 clips, leaving other tracks absolute; visual alpha crossfade and equal-power source audio mix. Appending V1 can extend the independent duration. G1 offers shared title presets. Direct rail placement, import/drop, track assignment, source trim, position, fit, opacity, color looks, gain, mute, fades, track gain/opacity, locks, snap, keyboard nudge and transactional undo/redo. Audio waveform analysis is on demand for supported imported audio.

Native A/V decode from Blob URLs with per-interval seek barriers, bounded active pool (up to four simultaneous video/visual clips including a V1 overlap, plus two audio), isolated paused still review, audio graph and real-time MediaRecorder output. Export pauses encoder while switching sources and rejects missing media, decode errors and excessive clock drift. Output supports WebM and MP4 when the browser offers that encoder. Canvas dimensions are independent of the source. Capture frame rate is requested rather than guaranteed frame-exact. Browser/hardware buffering and 4K/60 performance must be qualified separately. Max 64 clips, 200 assets, 512 MiB per video/audio, 64 MiB per still, 24 MP decoded source. GIF conversion is required here; existing Clip Studio GIF support unchanged. Waveform analysis is limited to 32 MiB/120 seconds/12 million decoded samples; audio playback/export uses native streaming rather than that analysis cache.

V3 JSON stores edit decisions and media metadata, not source bytes. Reopening creates local relink placeholders; matching filename, size, type and decoded duration/dimensions are checked (not cryptographic content identity). V1/V2 project conversion, full original Clip Studio recorder/cursor automation, advanced motion curves, generalized transitions, further track management, and frame-exact offline export remain separate future gates. No new extension permissions or main/stable promotion.

CI retains all existing gates and adds independent blank export, native source decode/dissolve/audio, source-linked save/relink, title and waveform output, and compact dialog qualification. Package only after every browser test passes.
