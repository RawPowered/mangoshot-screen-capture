# MangoShot v0.6.17 — Shortcuts & Command Menus (Alpha 1)

## Summary
One consistent keyboard preferences and searchable command system for Image Studio and Clip Studio. Capture, recorder, export, Wacom input, masking and timeline editing paths remain unchanged.

## Shortcut manager
Open from Help > Keyboard Shortcuts, Keys, or ? (Shift+/). Search commands and categories, click a binding to record a replacement, clear it, restore its default, or reset the editor's entire profile. Browser-reserved and duplicate combinations are rejected. Escape cancels key recording. Normal shortcuts do not fire in text fields, IME composition, focused buttons or dialogs. Shortcut settings are stored locally, never uploaded.

Each editor has an independent versioned v2 profile. Existing Clip Studio v0.6.5 customized key bindings migrate on first use. JSON export/import allows backup and restoration of the corresponding studio profile. Invalid, conflicting, oversized or cross-studio profiles are rejected without partial changes.

## Command palette
Open from Help > Search commands, Commands, or Ctrl+Alt+K. Search command name, group, action ID or binding; use Up/Down to navigate, Enter to run, Escape to exit. Actions call existing toolbar and editing operations instead of duplicating them.

## Image Studio menus
- File: import image, edit clipboard image, copy annotated screenshot, export PNG/PDF.
- Edit: undo, redo, duplicate/delete layers, confirm clear annotations.
- Layer: raise/lower, show/hide and lock/unlock selected layer.
- View: fit/100% and Wacom Browser Pen Test.
- Tools: select, pen, highlighter, brush/stroke erasers, text and width adjustments. Additional vectors remain in their Tools inspector.
- Help: shortcut settings and command search.

## Clip Studio menus
Existing File/Edit/Layer/View commands remain available with dynamic Undo/Redo/Split shortcut labels. Help, Commands and Keys launch the new UI. Select/Razor/Range, V/C/R, workspace presets, existing media import and editing commands are preserved. The prior v0.6.5 key listener yields to the new dispatcher to prevent double execution.

## Sample Image Studio defaults
Select V; Pen P; Highlighter H; Brush Erase E; Whole Stroke Erase Shift+E; Text T; Rectangle R; Ellipse O; Arrow A; Line L; Star Shift+S; brush smaller/larger [ and ]; Undo Ctrl+Z; Redo Ctrl+Shift+Z; Delete selected layer Delete; Duplicate Shift+D; Copy screenshot Alt+C; PNG Alt+P; PDF Alt+Shift+P; Fit Shift+0; Actual size Shift+9; Wacom test Alt+Shift+W; preferences ?; command palette Ctrl+Alt+K.

Clip Studio retains its previous defaults and custom bindings, adding Ctrl+Alt+K command search and Alt+E Export/Render.

## Application menu interaction
Native details and buttons support ArrowLeft/Right between menu headings, ArrowDown/Up through items, Home/End to jump, Escape to dismiss and click-outside to close. Live bindings appear beside menu commands and in tooltips. Shortcuts and palette use bounded, internally scrolling dialogs rather than increasing editor page length.

## Installation / rollback
The overlay requires an unpacked v0.6.16-wacom-erasers-alpha.1 directory. Back up the folder containing manifest.json, extract the overlay there and reload from chrome://extensions, edge://extensions or Firefox about:debugging. For older versions use the complete extension ZIP. Restore the backed-up v0.6.16 directory to roll back; avoid uninstalling or clearing local extension storage containing recordings.

No new extension permissions, external APIs, cloud sync or telemetry.

## Validation
Automated tests cover the legacy capture/recorder/Image/Clip/Wacom regressions, shared shortcut normalization and reserved-browser keys, editable and IME safety, binding conflicts, local Clip Studio migration, command dispatch, menu focus, Escape and outside-click behavior, dynamic key labels, full ZIP integrity and exact changed-file overlay.

Manual browser acceptance is still required for physical keyboard layouts, Chrome/Edge/Firefox reservation behavior, accessibility with keyboard/screen reader, focus restoration and high-DPI/mobile layouts. This release remains a development alpha until the hands-on gate passes.
