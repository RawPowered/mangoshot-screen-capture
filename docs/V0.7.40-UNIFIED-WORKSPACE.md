# Unified Creative Workspace (development)

This is the first structural UI pass, not a claim that both video runtimes have merged. Based on 6f5c08a0c767ff8e68e4974602a797529a68bd94. The previous v0.7.39 long-capture CI decoded a >52s recording with distinct early/late pixels and verified duration at editor handoff, but failed the primary-lane viewport assertion. Preserve that entire qualification gate. New shared action shelf takes ownership of existing Image Studio launch controls and groups frequently used drawing and precision commands; legacy inspector studio-button tree is removed from the default layout. Video shelf offers actual camera, cursor, animation, title, callout, transitions, color, layer and multitrack commands with visible icons and labels. At compact widths icons retain accessible names and tooltips; horizontal shelf scroll is deliberate. Existing menus and advanced dialogs remain for compatibility. Selected context's existing proxy inputs now have rotary dials and exact-value fields (same authoritative source; one commit per drag, numeric and keyboard editing). Image selection exposes rotation and opacity; direct image pen/marquee/arrow/box/ellipse shortcuts, plus a new real composed-pixel color sampler (no history or layer mutation). Primary video lane is placed immediately after ruler with compact 68px combined video/audio row; trim, waveform, thumbnails and timeline event handlers remain existing nodes. No new permissions, no asset rewrite, no new dependencies. Existing separate Sequence Studio remains separate; a future native model merge requires explicit project migration and parity work. More image tools (crop, healing, clone, fill, gradient brush, dodge/burn) require qualified native implementations; this pass exposes existing tools plus sampler, not those future capabilities. All package and recorder gates retained. New actual browser tests cover visible controls and user interaction, screenshots, full overlay after qualification. No main/stable merge.
