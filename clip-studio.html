Optional fast desktop export · cuts only

For high-end Windows PCs: save a MangoShot project JSON, keep the matching original video and run the bundled Node + FFmpeg helper. GPU H.264 encoding is attempted when available. This separate tool cannot render text/callout layers and refuses those projects.

node tools/fast-render.mjs --source "input.mp4" --project "MangoShot-Project.json" --output "edited.mp4" --encoder auto

Needs Node.js and FFmpeg on your PC. This local helper may render faster than real time; the browser exporter remains real-time.
